## 一、三条铁律

1. **字不可改。** 异体字、通假字、古今字保留原貌，不替古人「改正错字」；简繁转换须逐字核对，卦名、干支、书名尤须防「乾→干」、`系→繫`、`云→雲`、`后→後` 一类误转。
2. **义不可臆。** 先查旧注与字书，再参上下文；不望文生义，不增字解经，不以今天的词义去套古语。
3. **引必加白话。** 凡引一段文言，紧接一句白话直译；术语首次出现时给一句定义。宁可少引，不可引而不解。

## 二、常见虚词

| 虚词 | 常见用法 | 例句（出处） | 白话 |
| --- | --- | --- | --- |
| 之 | ①结构助词「的」 ②代词「它／他」 ③取消句子独立性 | 一阴一阳之谓道（《系辞上》） | 一阴一阳（的交替）叫做道。 |
| 其 | ①他的、它的 ②表揣测「大概」 ③表反问 ④将 | 其亡其亡，系于苞桑（《否》九五） | 将要灭亡啊、将要灭亡啊，（国命）系在丛生的桑树上。 |
| 而 | ①并且、却 ②然后、才 | 君子藏器于身，待时而动（《系辞下》） | 君子把器具藏在身上，等待时机才行动。 |
| 以 | ①因为 ②用、拿 ③用来 | 天行健，君子以自强不息（《乾·象》） | 天体运行刚健，君子因此自我奋发而不懈怠。 |
| 于 | ①在 ②对、向 ③比 | 君子藏器于身（《系辞下》） | 于＝在。 |
| 为 | ①做、作为 ②因为 ③被 | 易之为书也，广大悉备（《系辞下》） | 《易》作为一部书，广大而无所不备。 |
| 者 | ①……的人、……的事物 ②表停顿 | 仁者见之谓之仁，知者见之谓之知（《系辞上》） | 仁爱的人看见它（道）就叫它「仁」，聪明的人看见它就叫它「知」。 |
| 也 | ①表判断 ②表停顿、肯定 | 易，无思也，无为也（《系辞上》） | 《易》没有思虑，也没有作为。 |
| 乎 | ①表疑问、感叹 ②介词，同「于」 | 盖心在于《易》，忘乎其为寒暑也（《梅花易数》序） | 因为心全在《易》上，忘了（自己）身处寒暑之中。 |
| 焉 | ①于此、在这里 ②句末语气 | 三人行，必有我师焉（《论语·述而》） | 几个人同行，其中必有可做我老师的人。 |
| 哉 | 表感叹、反问 | 嗟乎，《易》岂易言哉（《梅花易数》观梅数诀序） | 唉，《易》哪里是容易讲的呢！ |
| 矣 | 表已然、肯定 | 温故而知新，可以为师矣（《论语·为政》） | 温习旧的而能明白新的，就可以做老师了。 |
| 乃 | ①于是 ②才 ③竟然 | 乾道变化，各正性命，保合大和，乃利贞（《乾·彖》） | 天道变化，万物各正其性命，保全大和之气，才是「利贞」。 |
| 则 | ①就 ②准则 | 穷则变，变则通，通则久（《系辞下》） | 走到尽头就变化，变化就通达，通达就能长久。 |
| 且 | ①而且 ②将要 | 不义而富且贵，于我如浮云（《论语·述而》） | 干不正当的事而得来的富贵，对我来说像浮云一样。 |
| 若 | ①如果 ②像 ③「若夫」＝至于 | 若夫杂物撰德，辩是与非，则非其中爻不备（《系辞下》） | 至于杂合事物、撰定德行、分辨是非，那就非靠中间四爻不可。 |
| 所 | 与动词组成名词性结构：……的（人、地、事） | 君子所居而安者，《易》之序也（《系辞上》） | 君子所安处而自得的，是《易》的次序。 |
| 与 | ①和 ②参与 | 易与天地准，故能弥纶天地之道（《系辞上》） | 《易》与天地相齐准，所以能包络天地的道理。 |
| 因 | ①凭借 ②于是 | 因贰以济民行，以明失得之报（《系辞下》） | 凭借（吉凶）二端来济助百姓行事，以明得失的报应。 |
| 遂 | 于是、就 | 寂然不动，感而遂通天下之故（《系辞上》） | 寂静不动，一有感通就能通晓天下的事故。 |
| 盖 | 表解说原因或推测 | 盖心在于《易》，忘乎其为寒暑也（《梅花易数》序） | 盖＝大概因为。 |
| 夫（fú） | 句首发语词 | 夫易，圣人之所以极深而研几也（《系辞上》） | 发语无实义，引出议论。 |
| 然 | ①这样、……的样子 ②然而 | 寂然不动（《系辞上》） | 然＝……的样子。 |
| 故 | ①所以 ②缘故、事故 | 感而遂通天下之故（《系辞上》） | 故＝事故、事情。 |
| 或 | 有的、有人、有时 | 无妄之灾，或系之牛（《无妄》六三） | 无妄的灾祸，有人把牛系在那里（却被人牵走）。 |
| 莫 | 没有谁、没有什么 | 法象莫大乎天地（《系辞上》） | 取法的象没有比天地更大的。 |
| 勿 | 不要 | 潜龙勿用（《乾》初九） | 潜伏的龙，不要施展作为。 |
| 相 | 互相 | 水火不相射（《说卦》） | 水火不相侵犯。 |
| 庶几 | 差不多、将近 | 颜氏之子，其殆庶几乎（《系辞下》） | 颜回这个人，大概接近（道）了吧。 |

## 三、常见句式

| 句式 | 识别标志 | 例句 | 白话 |
| --- | --- | --- | --- |
| 判断句 | 「……也」「……者，……也」 | 易，无思也，无为也（《系辞上》） | 《易》是没有思虑、没有作为的。 |
| 被动句 | 「见」「被」「为……所」 | 不见是而无闷（《乾·文言》） | 不被世人称是也不郁闷。 |
| 宾语前置 | 疑问句／否定句中代词作宾语前置 | 未之有也（古汉语通例） | 没有过这样的事。 |
| 介宾后置（状语后置） | 「于……」置于动词后 | 君子藏器于身（《系辞下》） | 君子把器具藏在身上。 |
| 定语后置 | 「……之……者」 | 马之千里者（古汉语通例） | 日行千里的马。 |
| 省略句 | 省主语、省「于」、省宾语 | 潜龙勿用，阳在下也（《乾·象》） | 省主语「龙」：龙潜伏不用，因为阳气在下面。 |
| 反问句 | 「岂……哉」「其……乎」「安……」 | 然则圣人之意，其不可见乎（《系辞上》） | 那么圣人的意思，难道就看不见了吗？ |
| 固定结构 | 「所以」「是以」「是故」「然则」「虽然」「何以……为」 | 是故易有太极，是生两仪（《系辞上》） | 因此《易》有太极，太极生两仪。 |

## 四、训诂方法

1. **据形求义。** 查《说文》，看字形所示本义，再引申。如「爻」，《说文》「交也」，象交错之形。
2. **据声求义（通假）。** 古书多借字，须以音求义。如《蒙》卦辞「匪我求童蒙」，「匪」通「非」；《乾》九二「见龙在田」，「见」读 xiàn，通「现」；《说卦》「兑，说也」，「说」通「悦」。
3. **据本文自训。** 古书常自下定义，最可信。《乾·文言》即自训四德：「元者，善之长也；亨者，嘉之会也；利者，义之和也；贞者，事之干也。」此处的「干」是枝干、骨干之干，**不是**卦名「乾」，不可混改。
4. **据对文、互文。** 上下文对举处可互推。如《系辞上》「仁者见之谓之仁，知者见之谓之知」，「知」即「智」，对「仁」而见义。
5. **据旧注。** 先王弼注、孔颖达疏，次朱子《本义》，再《御纂周易折中》所集宋元诸说；注家分歧处并列，不强作调和。
6. **据全书用例。** 同一字在同一书中的用法应前后一致；孤证不足立说。

**四条禁忌**：望文生义（把「贞」只解作「占卜」而不看训「正」的传统）、增字解经（原文没有的字不许添进去凑意思）、以今律古（用现代政治、科学概念硬套卦爻辞）、孤证立说（凭一处僻例推翻通训）。

## 五、易学专名的读写

**易误字形（简繁转换高危字）**

| 原字 | 易误作 | 说明 |
| --- | --- | --- |
| 乾（卦名） | 干 | 「乾一、兑二」，不得作「干一」；但「干戈」「天干」「事之干」仍是「干」。 |
| 繫（系属） | 系 | 「繫辭」今简作「系辞」，引用古本时保留「繫」。 |
| 雲（云气） | 云 | 云气义作「雲」，言说义作「云」，简化为「云」后须据文义分辨。 |
| 後（前后） | 后 | 君王义作「后」，前后义作「後」；简化后皆作「后」。 |
| 無／无 | 混用 | 《易》经传多作「无」（无咎、无妄），保留原字。 |
| 豐／丰 | 丰 | 卦名丰，古本作「豐」。 |
| 復／复 | 复 | 卦名复，古本作「復」；「复」亦为「復」之简化。 |

**常见读音**：彖 tuàn；爻 yáo；筮 shì；蓍 shī；夬 guài；姤 gòu；屯 zhūn（卦名）；否 pǐ（卦名）；贲 bì；睽 kuí；蹇 jiǎn；噬嗑 shì hé；艮 gèn。

**卦爻辞套语**：元亨利贞（大通而利于守正）、无咎（无灾无过）、悔亡（悔恨消失）、贞吉（守正则吉）、利涉大川（利于渡大河，喻可行大事）、利见大人（利于见贵要）、密云不雨（阴阳未交，事将成而未成）、勿用（不可施展）、无攸利（无所利）。

## 六、引文加白话的规则（供 AI 助手照做）

1. **引必有出处**：书名＋篇名，如「《系辞上》」「《乾·文言》」「《梅花易数·体用总诀》」。不可只写「古书云」。
2. **原文与白话成对**：先引原文（一句为限），紧接一句白话直译；长段则节引，切忌大段堆原文。
3. **逐句直译，不作过度意译**：卦爻辞的白话要贴着字面，宁拙勿巧；义理发挥另起一句，不与直译混为一谈。
4. **术语首见即释**：如「旬空」首次出现，随手一句「一旬中轮空的两个地支，主虚而不实」。
5. **不改字、不补字、不省字**：异体字保留原貌；明显讹字可标「（原文如此）」或以注说明，不可径改。
6. **注家分歧要标明**：如「贞」训「正」与近人训「卜问」，须写「旧注多训正，近人或训卜问」，不可择一冒充定论。
7. **不把自己的演绎算作原文**：凡属解卦者的发挥，写「按」「据此可推」，与引文分开。
8. **回复主体用现代汉语**：夹带的文言词句一律随手解释，不炫学、不堆砌。

## 七、怎样使用注疏

1. **先读白文**：自己断句一遍，标出不明白的字词。
2. **参王弼注、孔颖达疏**：王注简净，多明义理；孔疏详赡，多存旧说、辨名物。本库 `周易正义-王弼注.md` 即此系统。
3. **参朱子《本义》**：元明以来科举用本，重象占、重本义，与王注互有出入，正好对看。
4. **参《折中》集说**：清人汇集宋元诸家之说，便于横向比较；本库仅收上经选录。
5. **再参今人译注校对**：只作最后核对，不作唯一依据。
6. **读书留痕**：遇到异文、异读、异训，随手记下出处，卦案或笔记中亦标明来源，以备复盘。
