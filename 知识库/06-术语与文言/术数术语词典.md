## 一、易学基础

| 术语 | 白话解释 |
| --- | --- |
| 易 | 本义为「变易」，兼含「简易」「不易」三义，是《周易》推演变化的总纲。 |
| 三易 | 古代三种筮书——夏之《连山》、商之《归藏》、周之《周易》，今仅存《周易》。 |
| 太极 | 天地未分之前的混沌一气，是《易》推演的起点。 |
| 两仪 | 太极分出的一阴一阳，即阳爻与阴爻两种基本形态。 |
| 四象 | 两仪再各分阴阳，成太阳、少阴、少阳、太阴，对应六七八九四数。 |
| 八卦 | 三画卦共八个：乾☰、兑☱、离☲、震☳、巽☴、坎☵、艮☶、坤☷。 |
| 经卦 | 即八卦，三画成卦，是构成六十四卦的基本单位。 |
| 别卦 | 六十四卦，六画成卦，由上下两个经卦相重而成。 |
| 六十四卦 | 八经卦两两相重所得之六十四卦，每卦六爻。 |
| 爻 | 卦画的基本单位，阳爻画「—」，阴爻画「--」，六爻自下而上排列。 |
| 阳爻／阴爻 | 阳爻象征刚、动、明，阴爻象征柔、静、暗，是判断吉凶的基本单位。 |
| 爻位 | 六爻自下而上称初、二、三、四、五、上，位有阴阳贵贱之别。 |
| 当位 | 阳爻居初三五、阴爻居二四上，名为当位，象征名实相副。 |
| 失位 | 阳爻居阴位或阴爻居阳位，名为失位，象征位置与性质不合。 |
| 中 | 二爻为下卦之中、五爻为上卦之中，居中之爻多主吉。 |
| 中正 | 阴爻居二、阳爻居五，既得中又当位，称中正。 |
| 应 | 初与四、二与五、三与上两两相应，一阴一阳为相应。 |
| 敌应 | 相应之位两爻同为阳或同为阴，同性相斥，称敌应，主不相应。 |
| 比 | 相邻两爻的亲近关系，一阴一阳相比为得，同性相比为失。 |
| 承乘 | 下爻对上爻为「承」，上爻对下爻为「乘」；阴承阳、阳乘阴为顺。 |
| 卦德 | 八卦的性情：乾健、坤顺、震动、巽入、坎陷、离丽、艮止、兑说。 |
| 卦时 | 每卦所代表的具体时势，如屯为初生之难、否为闭塞之时。 |
| 卦主 | 一卦中决定卦义的主爻，多取五爻、唯一阳爻或唯一动爻。 |
| 上下经 | 《周易》分上经三十卦、下经三十四卦，共六十四卦。 |
| 元亨利贞 | 乾卦四德；白话为「大为亨通，利于守正」。 |
| 吉凶 | 得为吉，失为凶，是《易》断辞的两个极端。 |
| 悔 | 小有过失而可以改，介于吉凶之间，偏于转好。 |
| 吝 | 有所吝惜、行有艰难，偏于小凶。 |
| 咎 | 过失、灾患，「无咎」即善补过而无灾。 |
| 厉 | 危险，须警惕而未至凶。 |
| 孚 | 诚信、心诚，凡言「有孚」多主可信、可感通。 |
| 贞 | 正而固，守正不移。 |
| 无咎 | 无灾无过，善补过者可得。 |
| 本卦 | 起卦所得、未经动爻变化的原始卦。 |
| 变卦 | 动爻阴阳改变后所得的新卦，又称之卦。 |
| 之卦 | 同「变卦」，古称「之」，如「乾之姤」。 |
| 错卦 | 六爻阴阳全部相反的卦，又称旁通。 |
| 综卦 | 整卦上下颠倒所成之卦，又称反卦、覆卦。 |
| 互卦 | 取二三四爻为下卦、三四五爻为上卦组成的新卦，表事情中间过程。 |
| 先天八卦 | 伏羲八卦次序：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八，主对待。 |
| 后天八卦 | 文王八卦方位：坎北、离南、震东、兑西、巽东南、坤西南、乾西北、艮东北，主流行。 |
| 河图 | 传说龙马负图而出，其数以五居中、一六居下，术数用作配数定位之本。 |
| 洛书 | 传说神龟负书而出，其数戴九履一、左三右七，九宫数即由此出。 |
| 八宫 | 汉·京房分六十四卦为八宫，每宫八卦，用于纳甲、世应与六亲。 |
| 世应 | 世爻代表「我」，应爻代表「彼」，相隔两位，六爻筮法以此定主客。 |
| 纳甲 | 把天干地支配入六爻，如乾纳甲壬、坤纳乙癸，是六爻装卦的基础。 |
| 飞神 | 卦中已出现的爻；与之相对的伏藏之爻称伏神。 |
| 伏神 | 用神不上卦时，取本宫首卦同位之爻伏于飞神之下，称伏神。 |
| 卦气 | 以卦配节气、月份以论旺衰的学说，汉易用之尤多。 |
| 爻辰 | 以十二辰配六爻的学说，用于解经与推数。 |
| 十二消息卦 | 以复、临、泰、大壮、夬、乾、姤、遁、否、观、剥、坤配十二月阴阳消长的卦序。 |
| 阴阳 | 一切事物相对的两面：阳主刚、动、明，阴主柔、静、暗。 |
| 五行 | 木、火、土、金、水五种性质，相生相克构成术数推演骨架。 |
| 天干 | 甲、乙、丙、丁、戊、己、庚、辛、壬、癸，主天、主外。 |
| 地支 | 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥，主地、主内，兼主时辰月份。 |
| 六十甲子 | 天干地支相配成六十组，用以纪年月日时。 |
| 五行相生 | 木生火、火生土、土生金、金生水、水生木。 |
| 五行相克 | 木克土、土克水、水克火、火克金、金克木。 |
| 旺相休囚死 | 五行在当令、得势、休退、被困、受克五种状态的强弱判词。 |
| 刑 | 子卯相刑、寅巳申三刑、丑戌未三刑、辰午酉亥自刑，主伤损纠结。 |
| 冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥六冲，主冲动、变化、散离。 |
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未六对，主牵连、和合、成事。 |
| 三合局 | 申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局。 |
| 三会局 | 寅卯辰会东方木、巳午未会南方火、申酉戌会西方金、亥子丑会北方水。 |
| 害 | 子未、丑午、寅巳、卯辰、申亥、酉戌六害，主暗中妨害。 |
| 破 | 地支相破（如子酉、卯午），主破损、隔阂。 |
| 墓 | 五行收藏之地：水墓辰、木墓未、火墓戌、金墓丑，主收藏、困顿。 |
| 绝 | 五行气尽之地，如金绝于寅，主断绝、无望，须待生扶。 |
| 长生十二宫 | 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养，判五行之气的始终。 |
| 太岁 | 当年所值地支，为一年之主宰，冲太岁之支为岁破。 |
| 月建 | 以节气所临之月支为当月主宰，非农历月份。 |
| 日辰 | 当日的干支，六爻、六壬皆以日辰为主宰。 |
| 旬 | 十天干配十二支，十日为一旬，余二支为空亡。 |
| 旬空 | 一旬中轮空的两个地支，又称空亡，主虚、迟、无实。 |
| 月破 | 爻与月建相冲，称月破，主受挫、破败。 |
| 岁破 | 与太岁相冲之支，主大动、大损。 |
| 节气 | 一年二十四节气，用于定月建、定月将、定奇门局数。 |
| 节与中气 | 立春、惊蛰等十二「节」定月建；雨水、春分等十二「中气」定月将过宫。 |
| 农历 | 阴阳合历，梅花易数时间卦取农历月日之数起卦。 |
| 真太阳时 | 按当地经度与均时差修正后的太阳时，用以定时辰更准。 |

## 二、周易经传与读法

| 术语 | 白话解释 |
| --- | --- |
| 十翼 | 彖上、彖下、象上、象下、系辞上、系辞下、文言、说卦、序卦、杂卦十篇传文，旧题孔子作。 |
| 卦辞 | 系于卦下的总断之辞，如「乾：元亨利贞」。 |
| 爻辞 | 系于每一爻下的断辞，如「初九：潜龙勿用」。 |
| 彖辞 | 释卦辞的传文（《彖传》），多推卦象卦位以明卦义。 |
| 大象 | 释卦象的传文，如「天行健，君子以自强不息」。 |
| 小象 | 释爻辞的传文，附于各爻之后。 |
| 文言 | 专释乾、坤两卦的传文。 |
| 系辞 | 通论《易》理与筮法的传文，分上下两篇。 |
| 说卦 | 专述八卦取象、方位的传文。 |
| 序卦 | 说明六十四卦排列次序的传文。 |
| 杂卦 | 以相对两卦对举、错落释卦义的传文。 |
| 用九／用六 | 乾卦六爻皆动称用九，坤卦六爻皆动称用六，各有专辞。 |
| 卦名 | 六十四卦之名，如乾、坤、屯、蒙，多取象或取义。 |
| 卦序 | 六十四卦的排列次序，今本起乾、坤，终既济、未济。 |
| 卦画 | 六爻的阴阳符号及其排列，是卦的形体。 |
| 卦象 | 卦所象征的事物与情境，如乾象天、坤象地。 |
| 卦义 | 一卦的大义与所主之事，常由卦名、卦辞、彖象合看。 |
| 观象玩辞 | 读《易》之法：观卦象以明事理，玩味卦爻辞以求旨。 |
| 中爻 | 二、三、四、五爻统称中爻，其中三四五又为互卦取材之处。 |
| 卦变 | 因爻之往来变动而成另一卦的学说，用于解经与推数。 |
| 引经 | 断卦时引用卦爻辞作依据；须注明卦名、爻位并随口译白话。 |

## 三、梅花易数

| 术语 | 白话解释 |
| --- | --- |
| 梅花易数 | 旧题邵雍所传，以数起卦、以体用生克断事的占法，又称观梅数。 |
| 先天起卦 | 先得数、后得卦，以数起卦，如时间卦、数字卦。 |
| 后天起卦 | 先得卦、后取数，以物象起卦，如见老人属乾、见牛属坤。 |
| 时间起卦 | 年支数加农历月日数取上卦，再加时支数取下卦，总除六取动爻。 |
| 数字起卦 | 以报数起卦：第一数除八取上卦，第二数除八取下卦，两数之和除六取动爻。 |
| 物数起卦 | 以所见物件之数或字数起卦。 |
| 声音占 | 以听闻声音的次数、字数起卦。 |
| 字占 | 以字的笔画、字义或拆字起卦。 |
| 丈尺占／尺寸占 | 以所量物件的丈尺寸数起卦。 |
| 卦数 | 先天八卦数：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。 |
| 动爻数 | 起卦所得除数之爻位，梅花以动爻所在之卦为用卦。 |
| 体卦 | 卦中无动爻之卦，代表占者自己或主体。 |
| 用卦 | 卦中有动爻之卦，代表所占之事或对方。 |
| 互卦 | 取中间四爻组成，主事情中间过程与内情。 |
| 变卦 | 动爻变化后所得之卦，主事情结果与归宿。 |
| 体用生克 | 断梅花的根本：用生体吉、体生用泄、比和吉、体克用小吉、用克体凶。 |
| 比和 | 体用五行相同，主和顺无碍、事可成。 |
| 体党 | 与体卦同五行之互卦、变卦，党多则体势盛。 |
| 用党 | 与用卦同五行之互卦、变卦，党多则体势衰弱。 |
| 卦气旺衰 | 以四时论体卦强弱：春木旺、夏火旺、秋金旺、冬水旺、四季土旺。 |
| 三要 | 三要灵应篇所重者：耳、目、心，耳听目视心感以接外应。 |
| 十应 | 外应十项：天时、地理、人事、时令、方卦、动物、静物、言语、声音、五色；另有写字之应，后出附之。 |
| 外应 | 起卦之际偶然出现的声色物象，作为断卦旁证。 |
| 心易 | 以心感应起卦，不拘定时定式，是梅花高明处亦是难处。 |
| 万物类象 | 八卦所代表的万事万物，梅花断卦取象全靠此类。 |
| 八卦方位 | 后天方位：离南坎北、震东兑西、巽东南坤西南、乾西北艮东北。 |
| 向背 | 占者所处方位与卦象的向背顺逆，顺则吉、逆则阻。 |
| 动静 | 体用互变之中，动者用事、静者主事，须参动静以定迟速。 |
| 静占 | 所测之物安静不动、事尚无兆时，以卦气与方位断之。 |
| 坐端 | 占时占者端坐之方位，与卦位相参。 |
| 克应 | 卦中所显示、日后可验的具体物象与事象。 |
| 应期 | 所测之事应验的时间，梅花以卦气旺衰、体用生克定远近。 |
| 观梅占 | 邵雍观梅见雀争枝而占，得泽火革、互乾巽、初爻动，为梅花经典卦例。 |
| 牡丹占 | 邵雍为富家占牡丹，断其将被马踏，亦是梅花著名卦例。 |
| 占例十八门 | 梅花卷二所列占类：天时、人事、家宅、屋舍、婚姻、生产、饮食、求谋、求名、求财、交易、出行、行人、谒见、失物、疾病、官讼、坟墓。 |
| 变卦式八则 | 梅花卷三所列八种以变卦断事的定式。 |
| 十应奥论 | 梅花卷三论十应原理与用法的篇名。 |
| 观物洞玄歌 | 梅花论观物取象的歌诀。 |

## 四、六爻纳甲

| 术语 | 白话解释 |
| --- | --- |
| 六爻 | 以摇钱或掷钱成卦、配纳甲六亲六神以断事的筮法，又称纳甲筮法。 |
| 摇钱起卦 | 以三枚铜钱摇六次，自下而上成六爻。 |
| 掷钱 | 以三枚钱同时掷出，正面为阳记三、反面为阴记二，合数定爻。 |

## 八、断法总则

| 术语 | 白话解释 |
| --- | --- |
| 一卦一问 | 一次起卦只断一事，事多则另起，以免信息混杂。 |
| 无事不占 | 没有真实疑问不起卦，戏占则卦不应。 |
| 诚敬 | 起卦时心诚意専，是传统筮法的基本要求。 |
| 动静 | 断卦先看孰动孰静：动者显事、静者待时。 |
| 虚实 | 空、破、墓、绝为虚，旺、相、生、扶为实。 |
| 主客 | 体用、世应、日辰与用神之间，须先定主客再论生克。 |
| 旺衰 | 以月建日辰定五行强弱，是断吉凶先决条件。 |
| 生克 | 五行相生相克，是一切术数判断吉凶的基本关系。 |
| 制化 | 以他神制住克神、化解凶势，为断「有救」之凭。 |
| 通关 | 两神相克以中间之神通其气，主由阻转通。 |
| 远近 | 应期有远近，近在旬日、远在年月，须合卦气与人事参定。 |
| 迟速 | 动主速、静主迟，冲合刑害皆影响快慢。 |
| 进退 | 化进主进、化退主退，进神得势、退神失势。 |
| 得失 | 断事最终落在「得」与「失」，须以用神旺衰与生克定之。 |
| 趋吉避凶 | 占筮的落脚点：不宿命、不吓人，给出可做与不可做。 |
