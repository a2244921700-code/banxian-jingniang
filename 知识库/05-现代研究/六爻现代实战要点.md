# 六爻现代实战要点 · 编者整理

- 性质：编者整理。以《增删卜易》《卜筮正宗》《黄金策》《火珠林》诸古籍的通行断法为骨架，改写为现代可操作的步骤与检查表；**不是任何现代著作的复制**，现代取象部分参《现代取象对照.md》。
- 适用：本 Agent 用六爻（摇钱／手动爻）断现代事时的断卦规程。
- 边界：六爻是「象—数—时」的参考系统，不给医疗诊断、法律结论、投资指令，不作生死断言；结论须给「可做之事」与风险提示。
- 关联文件：`05-现代研究/现代取象对照.md`、`05-现代研究/现代易学与六爻梅花书目导读.md`、`03-六爻卜筮/增删卜易-原文.md`、`03-六爻卜筮/卜筮正宗-卷前（残卷）.md`。

## 一、起卦前（先做这五件事）

1. **先取时取地**：调 `gua_now` 取当前日期时间、农历干支、节气、真太阳时；六爻以**月建（节气月）**与**日辰**为纲，时辰影响有限但记录在案。
2. **一卦一问**：问题具体到「人、事、时、地」。反例：「我运气怎么样？」正例：「这次面试（某公司，本周内）能否进复试？」
3. **身份与立场**：问卦人是本人还是代问？男女老少、在职还是学生，直接影响用神取法（女占婚以官鬼为夫，男占婚以妻财为妇）。
4. **心诚与静**：摇钱前凝神，问题默念清楚；不戏占、不占人隐私、不代人问凶事。
5. **记录**：时间、地点、问题、六爻（自下而上）、动爻，记入卦案（`gua_case record`），日后可复盘验证。

## 二、装卦后的基础要素（逐项核一遍）

| 要素 | 看法 |
|---|---|
| 八宫与五行 | 以卦宫五行为「我」，定六亲；本宫卦为体，变卦看结果。 |
| 世应 | 世为求测人自身，应为对方／所问之事所系之人。世应生合主顺，冲克主阻。 |
| 六亲 | 父母（文书、长辈、房车）、兄弟（同辈、竞争、耗财）、子孙（小辈、技术、医药、平安）、妻财（财物、配偶女伴、受我支配者）、官鬼（官职、压力、疾病、女占之夫）。 |
| 六神 | 青龙（喜、新、酒色）、朱雀（口舌、文书、信息）、勾陈（田土、迟滞、牵连）、螣蛇（虚惊、缠绕、怪异）、白虎（伤病、争斗、凶信）、玄武（暗昧、欺瞒、盗骗）。六神只作**佐参**，不作主断。 |
| 月建 | 按节气月建（非农历月），为卦中旺衰之「提纲」。 |
| 日辰 | 为卦中旺衰之「主宰」，能生克冲合卦爻，力量大于动爻。 |
| 旬空 | 按日柱旬空，空者「有力而未实、暂不应事」。 |
| 动爻 | 动必有因。动爻是事情的「发端与变数」，变爻是「结果与回头之力」。 |
| 日冲 | 旺相静爻被日冲为「暗动」；衰弱静爻被日冲为「日破」。 |
| 伏神 | 用神不上卦，须在本宫首卦中找伏神；伏神旺相得生者「伏而可用」，休囚受制者「伏而难出」。 |

## 三、用神取法（现代事项对照）

| 所问之事 | 主用神 | 辅看 |
|---|---|---|
| 求职、升迁、考试名次 | 官鬼（职位、录用方） | 父母（文书、成绩、offer）、兄弟（竞争者） |
| 考试、证照、升学 | 父母 | 官鬼（名次）、子孙（发挥、忌神） |
| 求财、生意、投资盈亏 | 妻财 | 子孙（财源）、兄弟（分财、耗损）、官鬼（监管与风险） |
| 婚恋（男占） | 妻财 | 应爻（对方）、父母（婚书、家长意见） |
| 婚恋（女占） | 官鬼 | 应爻、子孙（子女、忌神）、兄弟（同辈干扰） |
| 疾病、身体（只提示） | 官鬼（病气） | 子孙（医药）、世爻（本人承受力）、父母（病历、慢病） |
| 出行、搬迁 | 世爻（自身）＋应爻（目的地） | 父母（车票、住处、文书）、兄弟（同行、耗财）、白虎（路上伤病） |
| 失物、寻人 | 财／应爻（失物、所寻之人） | 玄武（偷盗隐匿）、勾陈（遗落土中、迟滞） |
| 官非、纠纷 | 官鬼（对方、官方） | 父母（文书证据）、子孙（和解、免责）、兄弟（争执耗财） |
| 房宅、不动产 | 父母（房屋契约） | 二爻（宅）、艮坤（宅基田土）、官鬼（产权纠纷） |
| 宠物、身边小辈 | 子孙 | — |

> 用神取错，全盘皆错。遇「一事多象」时，先问清求测人最在意的是「人」还是「物」还是「过程」，再定用神。

## 四、断卦九步（固定次序，宁可慢）

1. **定用神**：按上表取主用神，另记世爻（自身）与应爻（对方）。
2. **看用神旺衰**：以月建、日辰为尺度。得月建生扶、日辰生扶者旺；月破、日冲克、休囚无生者衰。旺衰定「事之底子」，是吉凶的第一步。
3. **看世应关系**：世应用神之间生、克、合、冲。世生应（我求对方）、应生世（对方就我）、世克应（我能制事）、应克世（事来压我）、比和（顺遂）。
4. **看动爻**：动爻对用神、世爻是生是克；动爻自身旺衰；动爻所化之变爻对动爻是「回头生」还是「回头克」。
5. **看变卦与变爻**：变卦为结果、变爻为变数。化进神（如寅化卯）主进、化退神（卯化寅）主退；化空、化破、化墓、化绝须细看。
6. **看旬空与月破**：用神空、世爻空、动爻空，各有说法。真空（休囚无生又空）主事不成、人不在；假空（旺相有生而空）主「待时而应」。
7. **看六亲六神与取象**：在旺衰既定之后，用六亲、六神、卦象补足「是什么、在哪里、什么形态」。此步最忌喧宾夺主。
8. **看三合、六合、反吟、伏吟、三刑**：合主成（也有合绊）、冲主散（也有冲开）、反吟主反复翻覆、伏吟主呻吟不动、三刑主牵连纠葛。
9. **定应期**：见下节。应期是把「会不会」落到「何时」。

## 五、应期取法（现代时间尺度）

古法应期多取日、月，现代事项可映射为「天／周／月／季」：

| 状态 | 应期取法 | 白话 |
|---|---|---|
| 用神旬空 | 待出空之日／冲空之日；旺相空者待填实 | 事情在「空」的这段时间悬着，出空才落实 |
| 用神月破 | 待填实（值月／值日）或合破 | 破了须补，补上才有转机 |
| 用神入墓 | 待冲开墓库之日 | 暂时被「关起来」，冲开即出 |
| 用神受冲 | 待合之日；用神被合 | 待冲之日 |
| 用神动而化进／化退 | 进神取其「进」之支，退神取其「退」之支 | 进退各按其支定时 |
| 世应相合而事迟 | 取合处或冲合之时 | 合住则慢，冲开则动 |
| 忌神发动克用 | 待忌神受制（克忌、墓忌、绝忌）之时 | 障碍被压住的时候才成 |
| 用神旺相静而不动 | 取值日／值月，或生扶之日 | 时候到了自然应 |

**尺度换算建议**：问「本周内」→ 以日断；问「这个月」→ 以日、旬断；问「今年」→ 以月断；问「长期趋势」→ 以月、季、年断，并明说「大势而非定日」。

## 六、现代实战常见误断（自查清单）

1. **只看卦名断吉凶**：卦名只是提示（如「明夷」主晦，「屯」主难），旺衰动变才是骨。
2. **用神多取**：一事一用神为主，其余为参；多取则乱。
3. **忽略世应**：世应关系是「我与所问之事」的格局，不能只看用神。
4. **月建日辰混淆**：月建管「这个月的大势」，日辰管「当下的主宰」；月破与日破不同。
5. **真空假空不辨**：旺相有生之空为假空，休囚无生之空为真空。
6. **不听身份**：同一卦，男占婚与女占婚、在职与待业，用神与结论都不同。
7. **一卦多问**：一卦只答一事；多问必拆多卦。
8. **事后附会**：不挑与结论相符的象来圆，须先立断语再验证。
9. **六神当主断**：六神是佐证，见白虎不等于必伤病。
10. **越界断言**：不据卦断生死、断病名、断诉讼输赢、断股票涨跌。

## 七、现代输出规范（断卦之后）

1. **结论先行**：先一句「能／难／可成但有条件」，再展开。
2. **分层解释**：底子（旺衰）→ 格局（世应）→ 变数（动变）→ 时候（应期）→ 建议（可做之事）。
3. **术语随手白话**：说「用神旬空」要接一句「意思是这事眼下还悬着没落实」。
4. **给可行之路**：结论落到处方——先做什么、避开什么、什么时候再看。
5. **风险提示**：涉及医疗、法律、投资时明确「这不替代专业意见」。
6. **不吓人**：凶象说「有阻滞、须防某处」，不说「大祸临头」。
7. **留验证口**：记入卦案并约复盘时间（`gua_case record --followUpAt`），应验与否都记，才有长进。
