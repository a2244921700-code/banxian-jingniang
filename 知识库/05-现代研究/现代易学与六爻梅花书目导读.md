## 一、易学通论与经传研究（读「经」的路）

| 作者 | 代表作（常见印本） | 定位 | 要点与读法 |
|---|---|---|---|
| 高亨 | 《周易古经今注》（重订本，中华书局，1984）；《周易大传今注》（齐鲁书社，1979） | 古史辨一系，经传分治的奠基作 | 主张「以经解经」、区分「经」（卦爻辞）与「传」（十翼），训诂扎实、敢于疑古。读法：查字词古义、辨卦爻辞本事时用；其疑古结论不必尽从。 |
| 李镜池 | 《周易探源》（中华书局，1978） | 古史与筮辞研究 | 把卦爻辞当卜筮记录与史料看，重视「筮辞」分类与编纂过程。读法：理解卦爻辞「为何这样写」时用，不宜当断卦手册。 |
| 尚秉和 | 《周易尚氏学》（中华书局，1980）；《焦氏易林注》《焦氏易诂》《周易古筮考》（今有《尚秉和易学全书》汇编本，中华书局） | 象数派大家，尤精逸象与古筮 | 以象解易、广搜汉魏逸象，筮例考据极富。读法：查「某卦为何取此象」、追溯六爻取象源流时用；《周易古筮考》是古筮例的宝库，但须注意其断法与今之纳甲六爻不尽相同。 |
| 刘大钧 | 《周易概论》（齐鲁书社，1986）；《纳甲筮法》（齐鲁书社，1995 前后印本） | 当代学院派易学与纳甲筮法的系统整理者 | 《概论》讲源流、象数、筮法演变，可作总纲；《纳甲筮法》把六爻装卦、用神、动变讲成可检验的体系，是**现代六爻最值得先读的一本**。读法：先《概论》后《纳甲筮法》，配古籍原文对读。 |
| 金景芳、吕绍纲 | 《周易全解》（吉林大学出版社，1989） | 义理派，重卦德卦时 | 逐卦逐爻讲「时」与「德」，语言正大。读法：写解卦结论、讲人生建议时的义理底子。 |
| 黄寿祺、张善文 | 《周易译注》（上海古籍出版社，1989） | 译注体工具书 | 注、译、评俱全，查卦爻辞白话最方便。读法：日常引用经文的对照本。 |
| 朱伯崑 | 《易学哲学史》（华夏出版社，1995） | 易学思想通史 | 讲历代易学流派与哲学脉络。读法：需要说明「此说出于何派」时查考。 |
| 李学勤 | 《周易溯源》（巴蜀书社，2006） | 出土文献与易学源流 | 用帛书、竹简材料重审易学源流。读法：讨论卦序、筮数、早期易学时用。 |
| 廖名春 | 《周易经传十五讲》（北京大学出版社，2004） | 经传研究的现代讲义 | 兼顾文献与思想，条目清楚。读法：快速建立「经／传／学」三层框架。 |
| 傅佩荣 | 《傅佩荣解读易经》（线装书局，2006 前后印本）；《易经与人生》 | 哲学普及与人生解读 | 以义理与人生哲学为主，几乎不涉术数技法；讲卦象时重「德行与处境」。读法：用于把断语讲成「人生选择」，**不可当作六爻断法依据**。 |
| 南怀瑾、徐芹庭 | 《周易今注今译》 | 通俗今注 | 行文浅白、杂以杂说。读法：入门可翻，引用须以严谨注本复核。 |

## 二、六爻（纳甲筮法）古籍与今著

### 2.1 古籍（本知识库另有原文，见 `03-六爻卜筮/`）

| 书名 | 旧题作者／性质 | 定位 |
|---|---|---|
| 《火珠林》 | 旧题麻衣道者一系，纳甲筮法现存最早的系统文本之一 | 六爻「以钱代蓍」的源头文献，装卦、六亲、世应的老规矩多出于此。 |
| 《黄金策》 | 旧题刘基（刘伯温） | 骈体断语总纲，分门别类（身命、婚姻、仕宦、求财、疾病等），后世《卜筮正宗》全文收录并逐句注。是**断语范式的源头**。 |
| 《增删卜易》 | 清·野鹤老人（旧题，李文辉编次） | 六爻第一实战书。以大量卦例讲用神、月建日辰、动变、应期，删繁就简、敢于纠前人之失。读法：先读其「用神」「月建日辰」「动变」诸章，再读卦例。 |
| 《卜筮正宗》 | 清·王洪绪 | 体系最整齐的六爻教程：十八问、用神、六亲、六神、卦例俱全。读法：与《增删卜易》对读，一严整一灵活。 |
| 《易隐》 | 传·清人撰（曹九锡一系） | 取象细密、分门断法繁多，适合已有基础后扩充象法。 |
| 《易冒》 | 清·程良玉 | 论理精微、文字简古，重「理」与「机」，非入门书。 |
| 《断易天机》 | 旧题，坊刻本 | 图诀多、口诀化的断法汇编，可作速查，须防坊刻讹误。 |
| 《卜筮全书》 | 明·姚际隆（旧题） | 明代六爻资料的汇编，保存早期断法。 |
| 《易林补遗》 | 明·张世宝（旧题） | 以「补遗」体例收六爻各类断法，卷帙较大，宜按专题检索。 |

### 2.2 今著（只列要点，不引原文）

| 作者 | 代表作 | 定位与要点 | 版权提示 |
|---|---|---|---|
| 刘大钧 | 《纳甲筮法》 | 现代最系统的六爻教材：把装卦、用神、旺衰、动变、应期讲成可操作的规程，并附卦例。读法：先建立「用神—旺衰—动变—应期」四步骨架，再用古籍卦例校验。 | 仅作提要，引用须注明书名与版本并控制在必要范围。 |
| 邵伟华 | 《周易与预测学》（花山文艺出版社，1990） | 1990 年代推动六爻普及的代表作，把传统纳甲用现代语汇讲开，体系完整、门槛低。局限：部分论断过简、举例偏宣传，学术上争议较多。读法：**当作入门与熟练的例子书，不当权威**；断法仍以《增删卜易》《卜筮正宗》校正。 | 仅作提要。 |
| 王虎应 | 六爻讲义与卦例讲解（坊间印本，版本不一） | 当代六爻教学与实战代表，重卦例复盘、重取象与应期的具体化，讲解通俗、步骤细。读法：看其「如何从卦里读出现实事」的取象思路；具体书名与版次坊间混杂，引用前须核对。 | 仅作提要，不整段抄录。 |
| 尚秉和 | 《周易古筮考》 | 汇集历代筮例并加按断，是理解「古法如何断」的关键材料。注意：其中多为古筮法（非纯纳甲），与今之六爻有差别。 | 民国旧著，仍宜提要引用。 |

## 三、梅花易数书目

| 层级 | 书目 | 定位与读法 |
|---|---|---|
| 原典 | 《梅花易数》（旧题宋·邵雍撰，通行本；本知识库另存原文，见 `02-梅花易数/`） | 体用、互变、三要十应、声音字数起卦的总源。读法：先「体用总诀」「八卦万物类占」，再读占例。 |
| 源流 | 邵雍《皇极经世》《击壤集》 | 观物、元会运世的象数背景书，非占书；读《皇极经世》观物篇可明梅花「观物取象」之理。 |
| 象数旁参 | 尚秉和《周易尚氏学》逸象部分 | 查八卦逸象、扩充类象时用。 |
| 当代实践 | 象数一路的当代讲法（如以「心易」为名的讲稿，坊间印本版本不一） | 重「象由心生、触机而占」，可拓宽取象；但体系杂、缺校验，引用须谨慎、以原典为归。 |
| 哲学解读 | 傅佩荣《解读易经》 | 只作义理参照，不涉梅花技法。 |

## 四、怎么用这份书目（给 Agent 的操作建议）

1. **断六爻**：先《增删卜易》查同类卦例与断法 → 用《卜筮正宗》核对规程 → 用《纳甲筮法》校准概念 → 需要断语范式时查《黄金策》。
2. **断梅花**：先《梅花易数》体用总诀与类占 → 取象不够时查《周易尚氏学》逸象 → 义理升维时参《周易全解》《解读易经》。
3. **讲出处**：引古籍须注「书名＋篇名/卷次」；引今著只提「某书某说」并给白话概述，**不得整章复制**。
4. **不冒充权威**：今人说与古籍冲突时，先说明分歧，再取「当下之理」与「可验证之处」，不硬断。
5. **知识库检索**：用 `gua_kb` 检索原文，关键词如「用神」「月建」「旬空」「应期」「体用」「互卦」；限定书名用 `book` 参数（如 `增删卜易`、`梅花易数`）。
