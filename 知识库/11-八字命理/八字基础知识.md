## 零、三分钟入门

八字，又叫四柱：把一个人的出生年、月、日、时，各用一组天干地支表示，共八个字。以**日干**代表命主本人，看其余七个字与日干的生克关系（十神）、看月令（出生的节气月）定格局、看大运流年定时间线。

四句总纲：

1. **日干为主**：《渊海子平·论日为主》说「取日干为主，以年为根，以月为苗，以日为花，以时为果」。年为祖上根基，月为父母与成长环境，日为自己与配偶，时为子女与晚景。
2. **月令为提纲**：《渊海子平·继善篇》：「欲知贵贱，先观月令乃提纲。」出生在哪个节气月，决定五行旺衰的大势。
3. **中和为贵**：《渊海子平·继善篇》又云「太过无克制者贫贱，不及无生扶者夭折」——不是越多越好，是「需要的有、不需要的不添乱」。
4. **神煞为辅**：《渊海子平·四言独步》：「神煞相绊，轻重较量。」先看五行十神格局，神煞只作点缀（详见 `神煞大全.md`）。

## 一、阴阳五行

### 1. 阴阳

阴阳是同一事物的两面：动与静、外与内、刚与柔。八字里：

- 天干分阴阳：甲丙戊庚壬为阳，乙丁己辛癸为阴。
- 地支分阴阳：子寅辰午申戌为阳，丑卯巳未酉亥为阴（按地支顺序隔位分）。
- 十神分偏正：与日干**同阴阳**者为偏（比肩、食神、偏财、七杀、偏印），**异阴阳**者为正（劫财、伤官、正财、正官、正印）。

白话记法：同性相遇「同类相斥而偏」，异性相遇「相配而正」。正者多主稳定、名分；偏者多主灵活、偏门、不确定。但偏不等于坏，正不等于好，要看命局需不需要。

### 2. 五行生克

- 相生：木生火，火生土，土生金，金生水，水生木。
- 相克：木克土，土克水，水克火，火克金，金克木。
- 生克是一体两面：生我者给我资源（印），我生者耗我精力（食伤）；克我者约束我（官杀），我克者受我支配（财）。

《渊海子平·论五行生克制化》有一组很实用的辩证句（原文为文言，此处白话转述）：

- 「金旺得火，方成器皿」——太硬的东西要火来锻炼才有用；
- 「土多金埋」「水多木漂」「火多土焦」——生得太多反成负担；
- 「金能克木，木坚金缺」——克人者也会受伤；
- 「强金得水，方挫其锋」——太旺者宜泄不宜再助。

这组句子是「旺衰与流通」的源头，比死背「缺什么补什么」高明得多。

### 4. 中和与「病药」

命局如人体：太寒要暖，太燥要润，太弱要扶，太旺要泄，堵塞要通。古书把命局的毛病叫「病」，把治病的字叫「药」：

- 《滴天髓·知命》提醒「命贵中和，偏枯终于有损」；
- 《渊海子平·伤官说》有「四柱元有病，要去病；不去病不发」之语；
- 后世《神峰通考》专立「病药说」（待与库内原文核对）。

白话：先找出这个八字最别扭的地方（寒、燥、堵、偏、战），再找能化解它的那个五行或十神，这就是用神思路之一（见第五节）。

### 4. 地支之间的关系

- **六合**：子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合（一说合土、一说日月之合）。合主亲近、牵绊、合作，也主「合住」而不得动。
- **三合局**：申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局。三合是「抱团成势」，力量大于六合，须三支齐见或岁运补足。
- **三会方局**：寅卯辰会东方木、巳午未会南方火、申酉戌会西方金、亥子丑会北方水。三会成方，气势最专。
- **六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥。冲主动荡、分离、变动、急迫；冲开墓库、冲动忌神亦有吉用。
- **六害**：子未、丑午、寅巳、卯辰、申亥、酉戌。害主暗中妨碍、骨肉不睦、心病（《三命通会·论六害》）。
- **三刑**：寅巳申（无恩之刑）、丑未戌（恃势之刑）、子卯（无礼之刑）；辰午酉亥自刑。刑主刑伤、口舌、纠葛，现代断法须结合用神喜忌，不一律言凶（《三命通会·论三刑》）。
- **相破**：子酉、卯午、辰丑、未戌相破（寅申巳亥原为破，因属三合长生，多不取破论；诸家取舍不一）。

关系口诀：**合能解冲，冲能解合，刑害多主内耗，会局看气势。** 断事要落到「谁与谁作用、作用在哪宫位（年祖上、月父母、日己身、时子女）」。

## 三、十神

### 1. 十神是怎么来的

以日干为「我」，看其余天干（及藏干）与我的生克关系和阴阳同异，就得出十神。《三命通会·卷五·论古人立印食官财名义》分得很清楚：

- 生我者：印绶（正印、偏印）；
- 我生者：食神、伤官；
- 克我者：官煞（正官、七杀）；
- 我克者：妻财（正财、偏财）；
- 同我者：比肩、劫财。

阴阳同异定偏正：同阴阳为偏，异阴阳为正。偏正不是吉凶，是「方式不同」：正多循规蹈矩、名正言顺；偏多另辟蹊径、来得快去得也快。

《渊海子平·基础》用甲日为例列过十神别名：见甲为比肩兄弟，见乙为劫财败财，见丙为食神天厨寿星，见丁为伤官退财耗气，见戊为偏财偏妻，见己为正财正妻，见庚为偏官七杀将星，见辛为正官禄马荣神，见壬为倒食偏印枭神，见癸为印绶。这些别名在古籍里随处可见，须认得。

### 3. 十神的生克链条

- 相生链：财生官，官生印，印生比劫（身），比劫生食伤，食伤生财。
- 相克链：比劫克财，财克印，印克食伤，食伤克官杀，官杀克比劫。
- 记忆口诀：「财官印食，顺生为贵；杀伤枭刃，逆用为奇。」——吉神顺用（生扶保护），凶神逆用（制化驾驭），不是吉神就一定吉。

《渊海子平》各论的要旨（白话转述，原文见库）：

- **论正官**：官是贵气，喜身旺、印绶相生，忌刑冲破害、伤官克破。官多反不为福，贵在纯一。
- **论偏官/七杀**：杀如猛虎，身旺有制则化权，身弱无制则为祸；制太过亦不美，要「轻重得所」。
- **论正财**：财要身能任。身弱财多，是「富屋贫人」；财多生官，也要身健才受得起。
- **论偏财**：众人之财，慷慨而不吝，怕比劫分夺，也怕空亡。
- **论印绶**：生我护我，主智、主庇荫；最怕财来破印（贪财坏印），喜官星生印。
- **论食神**：主福气、食禄、寿元；喜身旺、喜财，忌倒食（偏印夺食）。
- **论伤官**：多才多艺而傲物；「伤官见官，为祸百端」，但伤官伤尽、配印或生财，反成大格。伤官生财者富，伤官配印者贵。
- **论劫财**：同辈争财，男命多克妻、破财；用得好可成团队、竞争之力。
- **论倒食**（偏印夺食）：偏印克食神，主福浅、事有始无终，须财制枭或合去。

### 4. 十神组合速记

| 组合 | 象义 | 要点 |
| 官印相生 | 体制内升迁、文书功名 | 官生印、印生身，最喜身不弱 |
| 杀印相生 | 压力化为权柄 | 杀有制、印有情，武职、管理 |
| 财官相生 | 因财得位、经营发家 | 身健能任，忌财多身弱 |
| 食神制杀 | 以才艺、谋略驾驭压力 | 食杀力量须相当，制太过则杀无力 |
| 伤官配印 | 才华得收敛而成名 | 印要得力，忌财破印 |
| 伤官见官 | 口舌、是非、离职、官非 | 须看有无财通关、印制伤 |
| 食伤生财 | 靠手艺、创意赚钱 | 身弱食伤重则泄气太过 |
| 财坏印 | 因钱误学、因利失靠山 | 印为用时忌见财，印为忌时反喜财 |
| 比劫夺财 | 合伙纠纷、破财、竞争 | 身弱财旺时比劫反为帮手 |

## 四、格局

### 1. 取格原则

《渊海子平·论月令》：「月为提纲，带官星印绶，则慷慨聪明、见识高人。」《子平真诠·论用神》以「八字用神，专求月令」为纲（待与库内原文核对）。取格大法：

1. 看月令本气（地支主气）是什么十神；
2. 看月令藏干是否透出天干（透出者力显）；
3. 月令本气不透、中气余气透出，可取「变格」；
4. 月令为比劫，取建禄格或阳刃格（月令为日干之禄或刃）；
5. 月令无可用之神，方看外格。

**取格不可先入为主**：不是看到伤官就是伤官格，先问月令是什么、透没透、有没有破。

### 2. 正格八格

| 格局 | 月令十神 | 成格要点 | 破格要点 |
| 正官格 | 正官 | 官星纯一、身旺、有印相生 | 伤官克官、刑冲破害、官杀混杂 |
| 七杀格 | 七杀 | 有制（食伤制、印化、刃合）、身不弱 | 无制而又财生杀、身弱 |
| 正财格 | 正财 | 身旺任财、有官护财 | 比劫夺财、身弱财多 |
| 偏财格 | 偏财 | 身旺、财有根、有食伤生财 | 比劫分夺、空亡、身弱 |
| 正印格 | 正印 | 官星生印、身弱得庇 | 财星破印、印重身旺无泄 |
| 偏印格 | 偏印 | 有财制枭、有杀化枭 | 枭神夺食、身旺无制 |
| 食神格 | 食神 | 身旺、食神生财、有印护 | 枭神夺食、食神太旺泄身 |
| 伤官格 | 伤官 | 伤官生财、或配印、或伤尽 | 伤官见官、身弱伤重、财印交战 |

### 3. 建禄、阳刃与外格

- **建禄格**：月令为日干之禄（如甲生寅月）。身旺，喜财官，忌再比劫叠见。《子平真诠》有「论建禄月劫」篇（待核）。
- **阳刃格**：月令为日干之羊刃（如甲生卯月）。刃喜官杀制、喜财印流通，忌再冲合引动。《子平真诠》有「论阳刃」篇（待核）。
- **外格/特殊格**：从格（从财、从杀、从儿、从势）、化格（十干化气）、专旺格（曲直、炎上、从革、润下、稼穑，《渊海子平·碧渊赋》已列名）。古书另有杂格一大批，《渊海子平·喜忌篇》点到：合禄格、印绶格、归禄格、壬骑龙背格、六乙鼠贵格、井栏叉格、刑合格、子遥巳格、丑遥巳格、拱禄拱贵、时上偏财格、六阴朝阳格等。

**外格红线**：真从格条件极严（全局无根、气势专一、无破无救）；杂格多为「成格条件苛刻、现代应验有限」。断时宁可按正格论而留余地，不可见一两个字就套奇格——参《滴天髓·知命》任氏对「混看奇格异局」的批评。

## 五、用神取法

### 1. 什么是用神

用神是命局最需要、最能「治病救命」的那个五行或十神；相神是辅助用神、成全格局的那个字（《子平真诠·论相神紧要》待核）。用神不是「缺的那个」，也不是「命里没有的那个」，而是**能让全盘流通、平衡、成格的那个**。

常见误判：五行缺金就补金，缺火就补火——这是「缺什么补什么」的街头说法，不是子平取用。古书明言「用神不可损伤」「用神有气则吉」，补错用神反助忌神。

### 2. 四大取用法

| 法 | 适用情形 | 取法 | 出处 |
| 扶抑 | 身强或身弱明显 | 身弱取印、比扶身；身旺取官杀、食伤、财抑身 | 《滴天髓·衰旺》《滴天髓·中和》 |
| 调候 | 命局过寒、过热、过燥、过湿 | 冬木喜火暖、夏金喜水润；寒者暖之、燥者润之 | 《穷通宝鉴·五行总论》《滴天髓·寒暖》《滴天髓·燥湿》 |
| 通关 | 两行相战、克战成灾 | 取中间能通关之神（金木战取水、水火战取木） | 《滴天髓·通关》 |
| 病药 | 命局有明显忌神结党或偏枯 | 找出「病」，取能制病之字为「药」 | 《神峰通考·病药说》（待核）、《渊海子平·伤官说》「有病要去病」 |

补充：调候与扶抑常冲突（如身弱又需要暖局），须权衡先后。实务次序：**先定格局所需（月令为体），再看日主强弱（扶抑为用），再看寒暖燥湿（调候润色），最后看两行通关（流通）。** 四法不是并列的四选一，而是「看命局缺什么就补什么方法」。

### 3. 取用步骤与核查

1. 定日主旺衰：得令（月令生扶）、得地（地支有根）、得生（印星有力）、得助（比劫多）四项合看，不可只看月令。
2. 定格局所需：月令成什么格，格局喜什么、忌什么（参第四节表格）。
3. 定用神：优先解决「命局最大的病」；无大病则取流通之神。
4. 定相神：用神是官，相神取财或印；用神是财，相神取食伤或官。
5. 验岁运：用神起运得地则发，行忌神运则滞；应期看用神与忌神的旺衰节点。
6. 反向核查：所取用神能不能解释命主已知的经历、性格、职业、家庭？解释不了，先怀疑取错，不硬拗。

## 六、大运与流年

### 1. 排大运

- 大运从月柱起排，一运管十年。
- 顺逆：**阳男阴女顺排，阴男阳女逆排**（以年干阴阳分男女）。
- 顺排举例：甲子年生男，月柱丙寅，大运为丁卯、戊辰、己巳……逆排则乙丑、甲子、癸亥……
- 起运岁数：从出生时刻到最近的换月节气，按「三日折合一年、一日折合四个月、一时辰折合十日」折算。《渊海子平》引《珞琭子消息赋》：「运行则一辰十载，折除乃三日为年。」现代有精确到日的算法，须与所用工具统一口径。

### 2. 大运、流年的用法

- 《渊海子平·论大运》：「子平之法，大运看支，岁君看干。」——大运重地支成势，流年重天干显事。今人多干支合看。
- 大运是「十年大环境」，流年是「一年具体事」。吉凶看是否生扶用神、激发忌神，而不是只看大运干支好不好听。
- 交运换运前后一两年最易起变化（搬动、转行、感情、健康）。
- **岁运并临**：大运干支与流年干支完全相同，力量倍增，好事坏事都放大，须看是否为用神。
- **伏吟、反吟**：岁运与命局地支相同为伏吟（原地打转、旧事重来），相冲为反吟（反复、走动、分离）。
- **太岁**：《渊海子平·论太岁吉凶》「太岁乃年中天子，故不可犯」；又云「日犯岁君，灾殃必重；五行有救，其年反必招财」。白话：流年与日柱冲克须留意，但命局有救应（印、贵人、合）则可化。古书「决死无疑」一类话不可照搬现代使用。
- 小运、胎元、命宫：古法有之，门派差异大，现代多作辅助，不必深执。

### 3. 岁运断事的四个落点

| 落点 | 看什么 | 现代对应 |
| 事业 | 官杀、印星、格局是否被引动 | 升迁、转岗、考核、创业 |
| 财 | 财星、食伤、比劫 | 收入、投资、破财、分账 |
| 感情 | 日支（夫妻宫）、配偶星 | 结婚、分手、异地、家庭矛盾 |
| 健康 | 用神受克、五行偏枯、忌神冲刑 | 体检、休息、就医提醒（不作诊断） |

## 七、排盘步骤

### 1. 备齐出生信息

要问清：公历或农历生日、出生时刻（越精确越好）、出生地（省市区，最好有经度）、性别。缺失时刻或地点要说明「按默认地点/按午时推算」，不可假装有精确定时。

### 2. 真太阳时与时辰换算

- 钟表时间（北京时间）只是行政时；八字定时辰要用**真太阳时**：真太阳时 = 北京时间 + （当地经度 − 120）× 4 分钟 + 均时差。
- 经度每差 1° 差 4 分钟。例：东经 116.4°（北京）比 120° 偏西 3.6°，约慢 14.4 分钟；乌鲁木齐（约 87.6°E）要慢两个多小时，跨时辰极常见。
- 均时差一年内约在 −14 到 +16 分钟之间，须查表或由天文公式计算，不可忽略。
- 时辰分界在偶数整点：23、1、3、5……，真太阳时落在界线上时，须向命主确认「按哪一边算」并说明流派差异。

### 3. 子时换日（务必先声明口径）

23:00—24:00 为晚子时，0:00—1:00 为早子时。日柱换日有两大流派：

- **子初换日（23:00 换）**：晚子时即算次日日柱；
- **子正换日（0:00 换）**：晚子时仍算当日日柱，仅时柱用次日子时。

两派各有传承，结论会差一天，进而影响日干、十神、格局。做法：先声明本项目采用哪种口径（建议以所用排盘工具/引擎为准并写进说明），同一命例前后保持一致，不可混用。

### 4. 定四柱

- **年柱**：以立春为界。立春前出生，年柱算上一年干支（不是农历正月初一，也不是元旦）。
- **月柱**：以节气为界。立春—惊蛰为寅月，惊蛰—清明为卯月……月干用「五虎遁」由年干推出。
- **日柱**：查万年历或由儒略日算法连续推算，八字日柱与农历日期无简单对应，必须查算。
- **时柱**：用「五鼠遁」由日干推出。

五虎遁（年上起月）：

| 年干 | 甲、己 | 乙、庚 | 丙、辛 | 丁、壬 | 戊、癸 |
| 正月（寅）起干 | 丙寅 | 戊寅 | 庚寅 | 壬寅 | 甲寅 |

五鼠遁（日上起时）：

| 日干 | 甲、己 | 乙、庚 | 丙、辛 | 丁、壬 | 戊、癸 |
| 子时起干 | 甲子 | 丙子 | 戊子 | 庚子 | 壬子 |

### 5. 排附加信息

日主（日干）、十神（天干加藏干）、纳音（六十甲子纳音，见 `神煞大全.md`）、十二长生（看日干在各支的状态）、旬空（按日柱查旬空）、大运、流年。

### 6. 断命顺序

**排盘 → 定月令格局 → 判日主旺衰 → 定用神相神 → 看十神组合与宫位 → 看大运流年 → 落到现代事项与建议。** 次序不可倒：先谈吉凶再补格局，必出错。

### 7. 排盘示例（结构示范）

古籍原例：岳飞命造，见于《渊海子平·论阳刃》——「癸未、乙卯、甲子、己巳」，甲日主，卯月为羊刃，年上癸水正印，时上己土正财。书上借此例说明「刃印相配」，也记其「一合一冲，虽贵亦遭刑」的结局。现代解读此类命例，须同时说明：历史人物结局有政治与时代原因，不可全归八字。

（注意：示例仅示范「柱、十神、格局、岁运」的读法，不作真实命例吉凶断语。）

## 八、十神与六亲、职业、健康、婚恋的现代取象

### 1. 六亲对应

参《渊海子平·六亲总篇》，传统映射如下：

| 六亲 | 男命主要看 | 女命主要看 | 白话说明 |
| 父 | 偏财 | 偏财 | 父亲、男性长辈、抚养资源 |
| 母 | 正印（偏印为偏母/祖辈） | 正印 | 母亲、庇护、文书与家宅 |
| 兄弟姐妹 | 比肩、劫财 | 比肩、劫财 | 同辈、朋友、合伙人 |
| 配偶 | 正财（偏财为偏妻） | 正官（七杀为偏夫） | 男看财、女看官；日支为夫妻宫 |
| 子女 | 七杀（男）、正官（女） | 食神、伤官（诸家分配不一：一说食神为男、伤官为女，一说伤官为子、食神为女） | 男命官杀为子，女命食伤为子；两说并存，用时说明 |

说明：传统「男尊女卑」「克夫克妻」等表述带时代烙印，现代只取「关系模式」之意（如正官为女命夫星，可读作「伴侣的约束与名分」），不照搬吉凶断语。重婚、嫁娶次数之类旧说一律不用。

### 2. 十神与职业（编者归纳，仅作参考）

| 十神 | 现代职业倾向 | 工作风格 |
| 正官 | 公务员、国企、管理、教育行政、法务 | 守规矩、重名分、晋升路线 |
| 七杀 | 军警、执法、外科、竞技、创业、销售攻坚 | 抗压、敢闯、竞争性强 |
| 正印 | 教育、学术、医护、文化、文书、公益 | 稳定、重学历、有靠山 |
| 偏印 | 技术、研发、设计、玄学、冷门专业 | 专精、独立、偏门 |
| 正财 | 财务、会计、实业、固定薪资 | 稳、细、积少成多 |
| 偏财 | 生意、投资、销售、资源整合、自由职业 | 灵活、敢投资、广结人缘 |
| 食神 | 餐饮、文化、艺术、内容创作、服务 | 享受、有才艺、少攻击性 |
| 伤官 | 传媒、演艺、营销、技术革新、自由职业 | 表达强、创新、不服管 |
| 比肩 | 合伙、独立执业、同专业圈子 | 自主、平等、重朋友 |

取象原则：看**用神与格局的十神**定主线，再看**旺而透出**的十神定副业，最后看大运引动。忌「见伤官就断必换工作」「见正财就断必进体制」这类单点断言。

### 3. 十神与健康（只作提醒，不作诊断）

- 五行配脏腑见第一节表；《渊海子平·论疾病》另有一句「甲肝、乙胆、丙小肠、丁心、戊胃、己脾乡、庚是大肠、辛属肺、壬是膀胱、癸肾脏」，是把天干直接配脏腑的简诀。
- 看用神受克、忌神旺而无制、五行偏枯受伤之处，对应易出问题的系统。
- 十神过旺/受制的常见倾向（编者归纳）：官杀过旺易压力大、睡眠差；食伤过旺易饮食不节、劳心；财星过旺身弱则易过劳；印星受克则易情绪与安全感不足；比劫过旺易冲动外伤。
- **必须提示**：八字健康取象只用于提醒体检与作息，不替代医学检查与诊断；不说不治、不猜病名、不推荐药物。

### 4. 十神与婚恋（现代用法）

- 男看财星（正财为妻、偏财为女友/情人意象），女看官杀（正官为夫、七杀为男友意象），同时须看日支（夫妻宫）与配偶星是否被冲合刑害、旺衰、是否入墓、是否落空亡。
- 夫妻宫（日支）为喜用、被生扶，主婚姻助力；为忌神、被冲克，主磨合多。合多主黏连，冲多主变动；男女都不可只看一字定婚配。
- 现代提醒：感情是两个人的选择与经营，八字看的是倾向与相处模式；不作「克夫」「必离婚」「嫁不出去」等断言，不作婚配对象的绝对判定。

### 5. 十神与性格（参《渊海子平·论性情》《三命通会·论性情相貌》）

| 十神重 | 性情倾向 | 反面 |
| 正官 | 守礼、负责、重名声 | 拘谨、怕犯错 |
| 七杀 | 果决、有魄力、行动快 | 急躁、好胜、压力大 |
| 正印 | 温和、好学、重体面 | 依赖、慢热、想得多 |
| 偏印 | 敏锐、专精、独立 | 多疑、孤僻、钻牛角尖 |
| 正财 | 务实、节俭、守成 | 保守、计较 |
| 偏财 | 大方、灵活、会来事 | 浮华、难守财 |
| 食神 | 乐观、有才艺、会享受 | 懒散、不争 |
| 伤官 | 聪明、表达强、有创意 | 傲气、好辩、易得罪人 |
| 比肩 | 自立、讲义气 | 固执、不听劝 |
| 劫财 | 敢闯、社交强 | 冲动、易破财、好胜 |

## 九、常见误区（断命前先读一遍）

1. **神煞当主**。神煞只是辅助，古人也批评「神煞古有百二十名，其说穿凿支离」（《三命通会·论诸神煞》）；《滴天髓·知命》任氏更直言「混看奇格异局，一切神杀，荒唐取用，桃花咸池，专论女命邪淫，受责鬼神」。先格局用神，后神煞。
2. **只看旺衰、忽略月令格局**。继善篇明说「先观月令乃提纲」。月令是命局气候，不看月令就谈身强身弱，多半谈错。
3. **见某十神就断某事**。见伤官必离婚、见七杀必凶、见财多必富、见印多必贵——全是单点谬断。十神要放到生克链条与格局里看。
4. **缺什么补什么**。用神不是「缺项」；补错五行反助忌神。取用看「病在哪、药是什么」。
5. **忽略真太阳时与子时换日**。时辰错一位，时柱全变；日柱换日口径不同，整盘十神都变。排盘前必须确认。
6. **以年柱或纳音论命**。子平以日干为主，《渊海子平·论日为主》讲得很明白；纳音、生肖只能作旁参。
7. **照搬女命旧说**。「克夫」「淫贱」「孤寡」等封建断语带有时代偏见，现代断命只取关系模式与性格倾向，不作人格污名。
8. **只看字面吉凶**。大运流年干支本身没有绝对好坏，要看它是生扶用神还是激发忌神。
9. **外格滥套**。从格、化格、专旺格条件极严；杂格多为古人炫技，现代应验有限。宁可正格论、留余地。
10. **宿命论与吓人**。八字讲的是「乘势与避害」，不是判决书。不作生死、绝症、破产、牢狱的断言；不作医疗、法律、投资的替代判断；结论必须落到「可做的事」。
11. **忽略现实变量**。同一八字，家庭、教育、地域、时代、个人选择都不同；命理只谈倾向概率，不提「注定」。
12. **巴纳姆效应**。模糊而人人可套的描述（「你外表坚强内心柔软」）不是断命。断语要能被证伪、能有时间点。
