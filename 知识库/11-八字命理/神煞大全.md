## 一、神煞总说

### 1. 神煞是什么

神煞是古人给干支组合起的「象征标签」：某字遇上某字，就贴一个名号，如「天乙贵人」「羊刃」「桃花」。它不是天上的实体星，也不是必然吉凶；本质是**一种取象的快捷方式**——把复杂的生克关系压缩成一个可记的名字。

### 2. 古人对神煞的批评（必须知道）

- 《三命通会·论诸神煞》开宗明义：「神煞古有百二十名，其说穿凿支离，造化恐不如是。」——连古代大家也嫌神煞名目太多、附会太甚，只挑「命中切要者」备论。
- 《渊海子平·四言独步》：「神煞相绊，轻重较量。」——神煞之间会互相牵制，要称量轻重，不能单看一个。
- 《渊海子平·喜忌篇》也说：「有见不见之形，无时不有；神煞相绊，轻重较量。」
- 《滴天髓·知命》任铁樵注更直接：批评时人「混看奇格异局，一切神杀，荒唐取用，桃花咸池，专论女命邪淫，受责鬼神」。这是清代命理大家对神煞滥用的当头棒喝。
- 《渊海子平·论太岁吉凶》：「神煞加临，轻重推之。」——神煞是「加临」的参考项，不是结论。

### 3. 神煞的三个层次

| 层次 | 例 | 用法 |
| 命局神煞 | 天乙、羊刃、桃花、魁罡 | 看性格倾向、助力与阻力，须结合格局旺衰 |
| 岁运神煞 | 丧门、吊客、病符、岁破、流年桃花 | 看某年某事的「触发点」，须结合用神喜忌 |
| 民俗神煞 | 童子煞、红艳煞等 | 民间流行，子平正统少用，只可作趣味参考，不可断事 |

### 4. 神煞取用的四条硬规则

1. **先格局用神，后神煞**：命局主线不清，谈神煞必是猜。
2. **吉神被制则不吉，凶煞有制则不凶**：天乙落空亡、被冲克，力减；羊刃有官杀制，反为权。
3. **看位置与多寡**：年柱主祖上少年，月柱主父母青年，日柱主自己中年，时柱主子女晚年；一柱独见力量有限，重叠才显。
4. **不许吓人、不许宿命**：古书上「主夭」「决死」「必孤寡」一类话，是古代术士的绝对化表述，现代断命一律不作生死、绝症、破产、牢狱断言；神煞只提示「倾向与留意点」（参 `八字基础知识.md` 第九节误区）。

### 2. 重点吉神详解

**天乙贵人**：神煞之首。《三命通会·论天乙贵人》说它「其神最尊贵，所至之处，一切凶煞隐然而避」，又详推阳贵、阴贵的起法：阳贵从子上起甲干顺行，阴贵从申上起甲干逆行，逐干各有两支（这就是「甲戊庚牛羊」一套口诀的来历）。要点：

- 同一日干有两个贵人支（一阳一阴），常见口诀只列两支，不标阴阳；《三命通会》则分阳贵、阴贵，用于昼占夜占。
- 贵人不喜落空亡、不喜被冲克、不喜与刑害并；「贵人多见空亡则可爱」是《三命通会·论空亡》里的特殊说法（贵人加空亡反主清高脱俗），可见同一神煞要结合空亡看。
- 现代用法：主「有人帮、有门路、遇事能转弯」，不可反过来断「命主必做大官」。

**天德、月德**：一对解厄之神。天德按生月查，一月一位；月德按三合局配天干。古书说「二德无破，女必贤良，男多忠孝」（《渊海子平·杂论口诀》），又云「素食慈心，印绶遂逢于天德」（《渊海子平·继善篇》）。现代取：心性宽厚、遇事有转机、少走绝路。提醒：德神怕冲怕合去，被冲则解厄之力减。

**文昌**：读书考试之星，但**起法两说**：通行的「甲乙巳午报君知，丙戊申宫丁己鸡，庚猪辛鼠壬逢虎，癸人见卯入云梯」；《三命通会·论太极贵》另载「文昌贵」作甲巳、乙亥、丙戌、丁辰、戊申、己午、庚寅、辛未、壬卯、癸丑。两说差别很大，断学业时须说明按哪一说，不可两头讨好。现代引申：考试、写作、表达、文书工作。

**禄神**：《三命通会·论十干禄》把十干禄与地支的吉凶细类讲得极细（如甲禄寅，见丙寅为福星禄、戊寅为伏马禄、庚寅为破禄、壬寅为正禄带截路空亡等）。要点：「禄随旺行」，禄是日主的根与衣食；最怕冲（破禄）、怕落空（闲禄），古书说「禄入空亡，虚名虚誉」。

**驿马**：三合局长生之冲位（寅午戌马申、申子辰马寅、巳酉丑马亥、亥卯未马巳）。主动象：出行、调动、外派、异地、奔波。现代取象可对应出差、搬家、异地工作、旅游、物流。提醒：马逢空亡主「白跑」，马被合住主「走不了」，须结合岁运引动。

**将星、华盖**：同出三合，将星取中位（帝旺），华盖取墓库。《三命通会·论将星华盖》说「将星处乎中军，华盖张乎库土」；将星须贵煞相扶方为吉庆，华盖多主孤高、艺术、宗教缘，「华盖逢空，偏宜僧道」（《渊海子平·造微论》有类似语）。现代取：将星为管理与领导力；华盖为专业深度、独处、清高、艺术或玄学兴趣。

**金舆**：《三命通会·论十干禄》附论：「金舆常居禄前二辰，如甲子人禄在寅，辰为金舆是也。」古书以金舆为「禄命之旌旗」，主配偶助力、富贵安车。现代取：车、房、配偶条件、生活品质；不可单凭一支断富贵。

### 2. 重点凶煞详解

**羊刃**：《渊海子平·论阳刃》：「甲禄在寅，卯为阳刃。」又说「五阳有刃，乙丁己辛癸五阴无刃」；《三命通会·论羊刃》则十干皆列，称阴干之刃为「阴刃」（身轻）。两说并存，用时说明。要旨：

- 刃是「极盛之气」：禄过则刃生，如刀口向外，能护身也能伤人。
- 「杀无刃不显，刃无杀不威」——《渊海子平·论阳刃》原话。有了七杀与羊刃相配，反主武权、决断、掌兵刑之职。
- 忌「刃逢冲合岁君」：流年冲刃、合刃，主变动、血光、是非；古书举岳飞命「卯刃」逢辛酉年冲合为例，但也须说明历史人物的结局有政治原因，命理只作象的举例。
- 现代用法：性格刚烈、能扛压、敢冒险；提示「注意外伤、冲突、冲动决策」，不作「必有血光」的断言。

**劫煞、亡神**：《三命通会·论劫煞亡神》说得很清楚：「劫者夺也，自外夺之之谓劫；亡者失也，自内失之之谓亡。劫在五行绝处，亡在五行临官。」——劫煞取三合局的「绝地」，亡神取三合局的「临官（禄）位」。古歌又说劫煞「吉则聪慧敏给、才智过人、武德横财；凶则昏浊邪侈、毒害性重、宿疾刑徒」，可见吉凶看与什么神煞搭配。现代取：劫煞主「外来破耗与竞争」，亡神主「内部失误与心机」。

**灾煞、六厄**：灾煞是「冲将星」之位（三合帝旺之冲），六厄是「三合局死地」。两煞都主阻滞、意外，但古书也承认「有福神相助多是武权」「有救扶逢生旺兼贵气相助则吉」。现代取：事业卡点、健康留意、出行小心，不渲染。

**勾绞、暗金的煞**：勾绞主「牵连羁绊」，最宜与「三刑、白虎」一起看是否成势；暗金的煞（破碎）取「四仲见巳、四孟见酉、四季见丑」，三命通会解释为「金能煞物」，主刑伤破损。二者在现代可读作「易卷入纠纷、易有破损损耗」，仍以格局用神为断。

**元辰**：《三命通会·论元辰》的推法：阳男阴女取年支冲位前一位，阴男阳女取冲位后一位；例如甲子男元辰在未（乙未），乙丑男元辰在午。古书说元辰「动摇颠倒不得宁息」，岁运逢之更显；但同篇也承认「大凡贵命须逢煞即得君王横升拔」——贵命不怕一煞。现代取：环境动荡、心神不宁、破财，提示「减少折腾、稳字当头」。

**孤辰寡宿**：三命通会的推法基于三会方局：如亥子丑方，进前一辰（寅）为孤、退后一辰（戌）为寡；其余三方类推。古书以「男孤辰、女寡宿」分论，主婚缘迟、六亲缘薄。现代用法：只取「独立性强、晚婚倾向、与原生家庭距离感」，绝不作「必孤寡」的判决。

**天罗地网**：三命通会解释「天倾西北，戌亥者六阴之终；地陷东南，辰巳者六阳之终」，阴阳终极则暗昧不明，如人在罗网。又说「火命人有天罗，水土命人有地网，余金木二命无之」，男女分看（男怕天罗、女怕地网）；重犯（如戌年戌月戌时）更显。现代取：易有阻滞与是非，须谨慎行事；不可只凭辰戌巳亥四字断大凶。

**十恶大败**：并非「十种恶事」，而是「六甲旬中十个日值禄入空亡」的日子——如甲辰、乙巳（甲辰旬以寅卯为空，甲禄寅、乙禄卯），壬申（甲子旬以戌亥为空，壬禄亥）等。古书说「命中犯者当以日上见之为是」，且「内有吉神相扶贵气相辅当为吉论」。现代取：易破耗、积蓄难，可作理财提醒，不作「必败」。

**魁罡、金神、日德、日贵、日刃**：这五个严格说是「日柱（或时柱）格」，古人归入神煞类。断法要以格局用神为主：如魁罡喜身旺、忌财官显露；金神喜火制；日德怕刑冲；日贵怕空亡；日刃喜官杀制。现代取：性格与行事风格的提示（刚断、慈善、贵气、果毅），不作绝对吉凶。

**阴差阳错、红艳、童子**：这三者在《三命通会》中未见（或未见专论），属通行神煞书与民俗，**起法与象义诸家不一**。现代用法：阴差阳错只提示「婚恋磨合多」；红艳只取「异性缘、人缘」；童子煞来自民间信仰，子平正统不用，只可作文化现象了解，绝不可据此断健康、断婚姻、吓唬命主。

### 2. 起法与查法

- 以日柱为主查旬空：如日柱在甲子旬，则四柱见戌亥为落空亡。
- 年柱、月柱、时柱也可单独查各自的旬空，但断命一般以日柱旬空为主，兼看年时。
- 《三命通会·论空亡》又分「五阳令用一阳、五阴令用一阴」：如甲子、丙寅、戊辰、庚午、壬申（阳）用戌不用亥；乙丑、丁卯、己巳、辛未、癸酉（阴）用亥不用戌。又分上下五年：甲子至戊辰以戌为空、己巳至癸酉以亥为空，并论「重见」与「轻见」之别。此类细法属流派差异，取用时说明即可。

### 3. 象义

空亡＝空、虚、无实、迟、不落实。用在人事上：计划未定、对方没到位、心里没底、事情悬着。但《三命通会·论空亡》也提醒「空而有实，亡而有存」，不可一见空亡就断「没有」：

- 旺相有生扶而空＝**假空**，逢出空、填实、冲空之年月即应；
- 休囚无生而空＝**真空**，主事难成、人难见；
- 贵人多见空亡反主「清高脱俗」（三命通会原文有「贵人多见空亡则可爱」）；
- 木空则朽、火空则发、水空则流（吉），金空则鸣、土空则崩（凶）——《渊海子平·六亲总篇》原文「金空则鸣，火空则发，水空则流，此三者上吉；木空则朽，土空则崩，二者主凶」。注意：不同书的五行空亡吉凶说法不一，须以命局用神为准，不可死套。
- 「互换空亡」：年柱与日柱互相落空（如甲子年壬戌日），古书认为灾重，须细看有无填实。

### 4. 使用提醒

空亡不是「没了」，是「暂时不实」。断事要落到：何时填实（值年值月）、何时冲开（冲空）、何时出旬。健康、婚姻、合作等事遇空亡，多主「迟、变、悬而未决」，用提醒与规划代替吉凶恐吓。

### 5. 截路空亡（历家另法）

《御定星历考原·日时总类》另列「截路空亡」：甲己日申酉时、乙庚日午未时、丙辛日辰巳时、丁壬日寅卯时、戊癸日子丑时。其意是「行路遇水不可行」，主行动受阻、事到中途而止。现代可读作「出行、办事易被卡住」，与旬空不是一回事，勿混用。

## 五、纳音类

### 1. 纳音是什么

纳音是六十甲子配五音十二律得出的「声音五行」，如甲子乙丑为海中金。原理见《三命通会·总论纳音》：「六十甲子纳音本六十律旋相为宫法也」，又引「同类娶妻，隔八生子」的律吕相生法。古人用它论年命、合婚、取象；子平法兴起后，以日干为主，纳音退为辅助。

《三命通会·论纳音取象》把六十甲子纳音的取象讲得很细（海中金、炉中火、大林木……各有一段象义），可作断事取象的参考，但不可取代日干十神。

### 3. 纳音用法与提醒

- **年命纳音**：古法以年柱纳音为「命身」，论一生大势；子平法以日干为主，年命只作旁参。
- **纳音合婚**：旧时流行「纳音相生则吉、相克则凶」，如金命与土命相生、金与水命相生等。现代只可作趣味参考，婚配以双方性格与现实相处为准。
- **纳音长生**：《三命通会》以纳音论长生、临官，用于学堂词馆、子息等古法；现代少用。
- **纳音取象**：断具体物象时可借纳音（如「海中金」主宝器沉藏、「覆灯火」主灯烛照明），但须与日干十神、格局用神相容，不可单凭纳音断吉凶。
- 提醒：《三命通会·论纳音》本身也辨析纳音与正五行的关系，主张不可只执纳音；现代断命更应以十神格局为主。

### 2. 干支字形煞（《三命通会·论干支诸字杂犯神煞》）

古人还从字形取象，列平头、破字、悬针、杖刑、阙字、曲脚、聋哑等煞，如「甲丙丁壬辰字谓之平头煞」「甲辛卯午申属悬针」「乙己丑巳属阙字曲脚」。这类取象极为穿凿，现代断命不用，只作了解古籍之用。若在旧书中遇到，说明「此为字形取象，现代不取」即可。

### 3. 与神煞易混的地支关系

六害、三刑、六冲、六合严格说不是神煞，而是地支之间的关系，已在 `八字基础知识.md` 第二节列明。断神煞时须注意：

- 神煞落点若同时被冲、合、刑、害，吉凶会变（如天乙被冲则力减，羊刃被合则动）；
- 「神煞逢冲」与「地支相冲」要分开讲，不可混为一谈。

### 4. 建除十二神（月建十二神）

《御定星历考原·日时总类》列「月建十二神」：建、除、满、平、定、执、破、危、成、收、开、闭，以月建上起「建」顺行十二辰。大义：建为岁君可坐不可向，除为小吉，满主盈满，平主平顺，定主安定，执主执持，破为大耗（最凶），危主危险，成为成就，收主收成，开主开张（吉），闭主闭塞。现代多用于「择日」，八字论命不必搬用；若遇用户问择日，可提一句「此为历法神煞，须与八字用神分开看」。

## 七、神煞使用总则（现代）

### 1. 优先级

**月令格局与用神 ＞ 十神旺衰组合 ＞ 宫位与岁运 ＞ 神煞。** 神煞永远排在最后，只用来「添一句话」：添性格色彩、添事情触发点、添提醒。

### 2. 六条操作规则

1. 先问：「这个神煞在命局里有没有根？被不被冲合？与用神是喜是忌？」四问不清，不谈吉凶。
2. 吉神凶煞都要「有引动」才应：命局有、岁运来引，才算事到临头；命局无、流年见，只作小提醒。
3. 一煞多象，只取与所问之事最贴的一象，不堆砌（参 `八字基础知识.md` 第九节误区）。
4. 吉神不因多而必吉，凶煞不因多而必凶；古书「贵人多、煞多」都各有破法。
5. 神煞组合要看「制化」：羊刃得官杀制、劫煞得贵人扶、空亡得填实，都是转机。
6. 女命旧说（克夫、寡宿、桃花淫贱等）一律不作人格评判与婚姻判决；现代只取关系模式与性格倾向。

### 3. 表达规则（与输出规范一致）

- 术语出现必带白话：如「羊刃——就是性格里的那股冲劲，像刀口朝外」；
- 不下绝对断语：不说「必」「注定」「主死」「没救」；
- 医疗、法律、投资相关只作提醒，必须提示「仅供参考，请询专业人士」；
- 八字断事落在「可做的事」：提醒体检、提示理财、建议沟通方式，而不是判生死。

### 5. 神煞的「引动」与应期

神煞本身不会「到时候自动发难」，要有人事引动：

1. **值年引动**：流年走到神煞所在之支（如命带驿马在寅，流年寅年）。
2. **冲合引动**：神煞被冲（动而显）、被合（牵绊而显）。
3. **填实引动**：空亡之神逢值年填实，或出旬。
4. **大运引动**：大运支带某煞，十年内该象常在；流年再引，事才发作。
5. **宫位定点**：神煞落年柱主祖上少年，月柱主父母青年，日柱主自己中年，时柱主子女晚年；应期看宫位与岁运叠加。

白话：命里有煞是「有这个可能」，岁运来引才是「事情发生」；断应期落到具体年月，说「哪一年容易碰到」，不说「哪一年必死」。
