## 例一　占求财 · 兑为泽变雷水解

- **出处**：《增删卜易》卷一·元神忌神衰旺章第十（维基文库本）

**原文**：

```
例：酉月辛亥日占求财得兑为泽卦变雷水解卦
父母未土⚋世 父母戌土⚋
兄弟酉金○ 兄弟申金⚋
子孙亥水⚊ 官鬼午火⚊
父母丑土⚋应 官鬼午火⚋
妻财卯木⚊ 父母辰土⚊
官鬼巳火○ 妻财寅木⚋
断曰：寅日得见财，亦如心。彼曰：卯木妻财爻空而月破，又被金克，初爻巳火官虽生世，亥日冲散又化旬空何以为吉。予曰：神兆机于动，予从来不言散，正因巳火化空，所以目下不见，待甲寅日出空而相见。寅木之财以生官，官来生世，果于寅日早见木日得财。
```

**编者按**：此例是「元神／忌神」与「动而化空」的示范。用神妻财卯木空而月破，看似无财；但初爻官鬼巳火发动化空，野鹤老人不从「冲散」「化空」断凶，而断「待出空之日相见」。断法的关节是：动爻化空不是没了，是时候未到；出空之日，生官、官生世，事乃成。

## 例二　占弟病 · 水火既济变雷水解

- **出处**：《增删卜易》卷一·克处逢生章第十三（维基文库本）

**原文**：

```
如辰月丙申日占弟癌症业已临危得既济卦变革卦
兄弟子水⚋应 官鬼未土⚋
官鬼戌土⚊ 父母酉金⚊
父母申金ㄨ 兄弟亥水⚊
兄弟亥水⚊世 兄弟亥水⚊
官鬼丑土⚋ 官鬼丑土⚋
子孙卯木⚊ 子孙卯木⚊
断曰：月建辰土虽克亥水，兄弟赖申日以生之，又得动爻相生，临危有救，果于本日酉时遇名医救活也，至己亥日以全生。
```

**编者按**：此例演示「克处逢生」。兄弟爻亥水为用神，月建辰土克之，本属凶；但日辰申金生亥水，又有动爻相生，由克转生，故断「临危有救」。要点：用神受月建之克未必死，得日辰与动爻生扶即可救；断病看用神旺衰与救应，不可只看一克字。

## 例三　占子痘症 · 风火家人变离为火

- **出处**：《增删卜易》卷一·三刑章第二十一（维基文库本）

**原文**：

```
如寅月庚申日占子痘症，得风火家人变离卦。
兄弟卯木⚊ 子孙巳火⚊
子孙巳火○应 妻财未土⚋
妻财未土ㄨ 官鬼酉金⚊
父母亥水⚊ 父母亥水⚊
妻财丑土⚋世 妻财丑土⚋
兄弟卯木⚊ 兄弟卯木⚊
断曰：巳火子孙既当春令，子孙旺相许之可治，后死于寅日寅时。后悟月建在寅，日建在申，与巳爻子孙共作三刑，独此一卦，无他爻之伤也，至于子卯、辰戌丑未亦有验者皆附和而为凶也。
```

**编者按**：此例是「三刑」的实证。巳火子孙当春令旺相，断者先许可治，后竟死于寅日寅时；复盘方悟月建寅、日建申与卦中巳爻凑成寅巳申三刑。要点：旺相不等于无凶，刑冲会合也能致命；凶应之日多在刑冲值日之时。

## 例四　占求财 · 风火家人变山火贲

- **出处**：《增删卜易》卷一·旬空章第二十六（维基文库本）

**原文**：

```
如辰月乙卯日占求财得家人之贲。
兄弟卯木⚊ 兄弟寅木⚊
子孙巳火○应 父母子水⚋
妻财未土⚋ 妻财戌土⚋
父母亥水⚊ 父母亥水⚊
妻财丑土⚋世 妻财丑土⚋
兄弟卯木⚊ 兄弟卯木⚊
断曰：丑财持世遇旬空，虽有巳火之生，巳火又化回头之克，不能生丑土之财，此财既无生扶当主难求。或又因三月之丑土财爻有气，古法有气不为空，不敢竟断，命之再占。
```

**编者按**：此例是「旬空」的示范。妻财丑土持世而旬空，巳火子孙发动本可生财，却化子水回头克，生财之路自断，故断「此财既无生扶当主难求」。野鹤老人又因三月丑土有气（古法「有气不为空」）不敢遽断，改用「再占」之法核实——这是《增删卜易》常用的谨慎手段：一事疑而不决，命之再占，以两卦互参。

## 例五　占将来有官否 · 兑为泽化天水讼，再占水地比

- **出处**：《增删卜易》卷二·月破章第二十七（维基文库本）

**原文**：

```
如亥月己丑日占将来有官否。得兑化讼卦
父母未土ㄨ世 父母戌土⚊
兄弟酉金⚊ 兄弟申金⚊
子孙亥水⚊ 官鬼午火⚊
父母丑土⚋应 官鬼午火⚋
妻财卯木⚊ 父母辰土⚊
官鬼巳火○ 妻财寅木⚋
此卦官动而生世，世动化进神，虽然有官之象，但官逢月破，世遇旬空，然空者犹月日辰相冲，冲空则实不为空矣，而破者又无日辰动爻之生，占以日建亦生不起，况无日建动爻以生乎？予疑之即无所用，何故动而生世？命之再占，又得出水地比卦。
妻财子水⚋应
兄弟戌土⚊
子孙申金⚋
官鬼卯木⚋世
父母巳火⚋
兄弟未土⚋
断曰：命若无官，官不得生世持世，今即前卦动。官相生，后得官临世位，食禄王家终须有日。彼问：应在何年？予曰：前卦官临月破，定于实破之年，果于巳年承袭长房世职，若以月破，百无所用，霄壤之隔也。
```

**编者按**：此例演示「月破」与「再占」。前卦官鬼巳火月破、世爻旬空，看似无望；野鹤老人不据一卦武断，命之再占，后卦官临世位，遂断「终须有日」，后于巳年承袭世职。要点：月破须待「实破」之年月日；凶中藏吉，要靠再占与旺衰合参。

## 例六　占官 · 泽水困变兑为泽

- **出处**：《增删卜易》卷二·飞伏神章第二十八（维基文库本）

**原文**：

```
有子月戊寅日占官得困之兑卦
父母未土⚋ 父母未土⚋
兄弟酉金⚊ 兄弟酉金⚊
子孙亥水⚊应 子孙亥水⚊
官鬼午火⚋ 父母丑土⚋
父母辰土⚊ 妻财卯木⚊
妻财寅木ㄨ世 官鬼巳火⚊
彼断曰：飞爻午之官已临破矣，巳官伏神长生于寅，至孟春必得升迁。予断之：黄金策曰，飞爻变爻俱无用神者，始寻伏神。此卦初爻寅木变出巳火官星，孟春官遇长生，且财爻独发亦生官矣。不曰变出之官而曰伏神者，何也？幸次卦伏神变爻皆巳火也。倘后人遇他卦，亦执此为法，用变爻乎？用神乎？非传世教人之法而不取也。
```

**编者按**：此例是「飞伏神」的辨法。别人以前卦飞神午火之官为用，断「孟春必得升迁」；野鹤老人驳之：初爻寅木动而变出巳火官星，当以变爻之官为用，不必另寻伏神，否则「用变爻乎？用神乎？」自相矛盾。要点：伏神是「用神不上卦」时的补救，不可有变爻之官仍去找伏神；取用神须先看动变所出。

## 例七　占子病 · 火天大有变火泽睽

- **出处**：《增删卜易》卷二·进神退神章第二十九（维基文库本）

**原文**：

```
又如辰月乙未日占子病得大有变睽，同时祖又占子孙亦得此卦
官鬼巳火⚊应 官鬼巳火⚊
父母未土⚋ 父母未土⚋
兄弟酉金⚊ 兄弟酉金⚊
父母辰土○世 父母丑土⚋
妻财寅木⚊ 妻财卯木⚊
子孙子水⚊ 官鬼巳火⚊
断曰：父母临月建化退神，此子死于次日。
```

**编者按**：此例极短而警醒：父母辰土持世发动，化出丑土，为「化退神」。原书断「此子死于次日」——凶应之速，正在「临月建而化退」四字。要点：化进主进、化退主退；吉神化退则吉渐消，凶神化退则凶渐减，仍须合旺衰与用神看，不可一概。

## 例八　占财 · 天火同人变乾为天

- **出处**：《增删卜易》卷二·两现章第三十二（维基文库本）

**原文**：

```
如戊寅日占财得同人之乾卦
子孙戌土⚊应 子孙戌土⚊
妻财申金⚊ 妻财申金⚊
兄弟午火⚊ 兄弟午火⚊
官鬼亥水⚊世 子孙辰土⚊
子孙丑土ㄨ 父母寅木⚊
父母卯木⚊ 官鬼子水⚊
用爻入墓，喜得日辰克破，后果得财。以用空入墓许以无财者，非也，殊不知虽空而遇冲，冲空则实，虽墓而克破，破墓则开。
野鹤曰：此极有理
```

**编者按**：此例演示「用神入墓」的解法：用神入墓本主受困，但日辰冲克墓爻，「破墓则开」，故断得财。原文并申明分寸：须「用神有力」方许；若用神休囚无气，虽逢冲开之日也难发。要点：墓、空、破都不是绝路，关键看能不能「冲开」「填实」，以及用神本身有无气力。

## 例九　占本日阴晴 · 风泽中孚变风天小畜

- **出处**：《增删卜易》卷二·天时章第三十五（维基文库本）

**原文**：

```
如辰月戊申日占本日阴晴得中孚之小畜卦
官鬼卯木⚊ 官鬼卯木⚊
父母巳火⚊ 父母巳火⚊
兄弟未土⚋世 兄弟未土⚋
兄弟丑土ㄨ 兄弟辰土⚊
官鬼卯木⚊ 官鬼寅木⚊
父母巳火⚊应 妻财子水⚊
丑土兄动化进神临月令，长生于申日，若论旺衰，旺之无比，并不见狂风累日，只见一日阴云而已。或曰：兄动化进神不见狂风者，以何爻而至狂风？予曰：水动化进神乃狂风可。
```

**编者按**：此例见《增删卜易》断天时的路数：兄弟丑土动化辰土，为「化进神」而临月令、长生于日，按常法当主狂风，实际只有一日阴云。野鹤老人自己总结：断天时不能死执「兄动化进则风」，仍须以五行为主、以旺衰定轻重。要点：象有常法，也有变例；不可拿一句口诀当铁律。

## 例十　占终身财福 · 水地比变风地观

- **出处**：《增删卜易》卷三·终身财福章第三十七（维基文库本）

**原文**：

```
如戌月辛亥日占终身财福得比之观卦
妻财子水ㄨ应 官鬼卯木⚊
兄弟戌土⚊ 父母巳火⚊
子孙申金⚋ 兄弟未土⚋
官鬼卯木⚋世 官鬼卯木⚋
父母巳火⚋ 父母巳火⚋
兄弟未土⚋ 兄弟未土⚋
断曰：世爻虽空，月建合之，亥日生之，子水财爻动而生世，卯年一定成家，丑年占卦，果至卯年立业成家。彼时定鼎之初，云贵才平，此人于川中带出附子黄莲桑材数担，勃然家蓄数千余金，从此立业成家，连年丰足，此岂可谓终身作事无成耶？
```

**编者按**：此例是「世空而得生扶」的示范。世爻虽旬空，月建合之、日辰生之，子水财爻动而生世，故断卯年成家立业，后果然。要点：占终身不能以一时的空破定死；空而逢合逢生，待出空之年月即应。断终身须看「大势与气脉」，不可拿日常占事的应期尺度硬套。

## 例十一　占终身功名 · 地火明夷变雷火丰

- **出处**：《增删卜易》卷三·终身功名有无章第三十八（维基文库本）

**原文**：

```
如辰月乙未日占终身功名有无得地火明夷变丰卦
父母酉金⚋ 官鬼戌土⚋
兄弟亥水⚋ 父母申金⚋
官鬼丑土ㄨ世 妻财午火⚊
兄弟亥水⚊ 兄弟亥水⚊
官鬼丑土⚋ 官鬼丑土⚋
子孙卯木⚊应 子孙卯木⚊
此公原是武荫，巳任裨官，因病告退，即无官矣。问将来还有功名否？此卦丑土官星持世，化出午火，财旺生官，卯年占卦，巳年援例连连加纳，官至府佐，未年出仕，戌年升任。黄堂古法以动而逢冲谓之散，此系未冲世爻之丑土，竟不见其散也。
```

**编者按**：此例讲「动而逢冲」：世爻丑土官星发动，未日冲之，古法谓「动而逢冲则散」，此卦却不见其散，反主官运通显。野鹤老人的判断是：丑土官星持世、化出午火、财旺生官，气势正盛，冲之不动。要点：冲散之说须以旺衰为前提——旺相逢冲是「冲起」，衰休逢冲才是「冲散」。

## 例十二　占防流兵 · 地泽临变火泽睽

- **出处**：《增删卜易》卷三·趋避章第四十（维基文库本）

**原文**：

```
如巳月戊辰日占防流兵得临之暌卦
子孙酉金ㄨ 父母巳火⚊
妻财亥水⚋应 兄弟未土⚋
兄弟丑土ㄨ 子孙酉金⚊
兄弟丑土⚋ 兄弟丑土⚋
官鬼卯木⚊世 官鬼卯木⚊
父母巳火⚊ 父母巳火⚊
彼时流兵为害，到处遭殃，此人知易占得此卦，终日焦忧，予问其故，彼曰：巳酉丑合成金局而克世，世爻又临腾蛇之鬼，数在结中，乃万莫能逃矣。予笑而曰：尔与兵贼同居，保尔无事。彼曰：何也？予曰：子孙合成金局，克去身边之鬼，夫复何忧？彼曰：酉金子孙，旺于巳月，又化巳火，论克如何论生？予曰：酉金得丑未二土以相生，如何为克？后此人屡次遇兵变，或避之，或有惊无险，自癸未占卦到地方安定。彼曰：子孙福神，信乎有验，世之看书不到，论理不彻，以吉为凶者，不独我一人而已。
```

**编者按**：此例是「以子孙克鬼」的实战。求测人见巳酉丑三合金局克世、世临螣蛇之鬼，以为必死；野鹤老人却断「子孙合成金局，克去身边之鬼」，后屡遇兵变皆有惊无险。要点：占祸患，先辨「克我者」与「克鬼者」谁强；子孙为福神，鬼为祸神，福神成局则祸不能侵。

## 例十三　占岁考 · 泽风大过变火风鼎

- **出处**：《增删卜易》卷三·岁科考章第五十（维基文库本）

**原文**：

```
如申月乙巳日占岁考得大过之鼎卦
妻财未土ㄨ 子孙巳火⚊
官鬼酉金○ 妻财未土⚋
父母亥水⚊世 官鬼酉金⚊
官鬼酉金⚊ 官鬼酉金⚊
父母亥水⚊ 父母亥水⚊
妻财丑土⚋应 妻财丑土⚋
断曰：财动克父，乃不通变之论也。此卦乃亥水父爻持世，申月生之，父旺而身亦旺，巳日冲之，为暗动，未土财爻虽动，喜其生助酉金，酉官生世，名为接续相生，一定篇篇华锦。财生官旺优等。后果取超等补禀。
```

**编者按**：此例破「财动克父」的死法：妻财未土发动，古法以为克父母（文书、考试）之凶象；野鹤老人看的是全盘——父母亥水持世、申月生之而旺，巳日冲之为暗动，未土之财反去生酉金之官，官又生世，「接续相生」，故断优等，后取超等。要点：六亲生克要看流转，财生官、官生世的「接续相生」，比单看「财克父」更合全象。

## 例十四　占求财 · 泽火革

- **出处**：《增删卜易》卷三·求财章第六十八（维基文库本）

**原文**：

```
如酉月戊午日占求财得革卦
官鬼未土⚋
父母酉金⚊
兄弟亥水⚊世
兄弟亥水⚊
官鬼丑土⚋
子孙卯木⚊应
断曰：卦中财爻不现，亥水兄爻持世，父临月建生助兄爻，如缘木以求鱼也。
```

**编者按**：此例短而干脆：卦中财爻不现，兄弟亥水持世，父母酉金临月建又生兄弟，财无来源而耗散之神得势，故断「如缘木以求鱼」。要点：求财先看财爻有无、旺衰与来源（子孙），再看兄弟是否夺财；财不上卦，多主「无财可求」或「财不归我」。

## 例十五　女家代占婚 · 地泽临变水火既济

- **出处**：《增删卜易》卷四·婚姻章第八十二（维基文库本）

**原文**：

```
又如寅月丙午日女家代占婚得临之既济卦
子孙酉金⚋ 妻财子水⚋
妻财亥水ㄨ应 兄弟戌土⚊
兄弟丑土⚋ 子孙申金⚋
兄弟丑土ㄨ 妻财亥水⚊
官鬼卯木○世 兄弟丑土⚋
父母巳火⚊ 官鬼卯木⚊
觉子曰：女家占男，以官为用，以应爻为男家，此古法也，亦死法也，断卦之时，须要人之活变，未必全得显而易见者，即如此卦，女家占男，卯木旺官持世，其婚必成，而应爻受克，又为男家不允，似此何以决之，要知财官为重，世应为轻，虽是女家占男，亦要财爻不致于换陷，此—卦也，男女二人财被回头克又逢丑土之克，如何能生卯木之官？男女不能相合相生，婚虽成终有他变，后果聘定于四月，未及成婚被贼兵劫去，应巳月者亥水逢月破也。
```

**编者按**：此例是「财官为重、世应为轻」的示范。女家占男，卯木旺官持世，照世应看其婚必成；但应爻受克、财被回头克又逢丑土之克，财不能生官，男女不能相生相合，故断「婚虽成终有他变」，后果被兵劫去。要点：婚姻卦以财官为骨、世应为皮；皮相合而骨不相生，事终难谐。

## 例十六　占仆人何日回 · 泽火革变泽天夬

- **出处**：《增删卜易》卷四·行人章第九十四（维基文库本）

**原文**：

```
又如亥月甲子日占仆人何日回得革之夬卦
官鬼未土⚋ 官鬼未土⚋
父母酉金⚊ 父母酉金⚊
兄弟亥水⚊世 兄弟亥水⚊
兄弟亥水⚊ 官鬼辰土⚊
官鬼丑土ㄨ 子孙寅木⚊
子孙卯木⚊应 兄弟子水⚊
此卦若问仆人在外之吉凶者，必不归矣，何也？午火财爻伏而破日月之克，今问何日可到，不以此断，世空者速至，此人来矣，巳日必到，应巳日者，冲空之日也，巳火又是财爻，果于巳日到。
```

**编者按**：此例示范「占行人」与「占吉凶」用神不同的道理：同一卦，若问仆人在外吉凶，则财爻伏而破、受日月之克，必不归；今问「何日可到」，则以世爻为主，「世空者速至」，断巳日到，果验。要点：一事一用神，问法不同则取用不同；断语须先锁定「到底问什么」。

## 例十七　占家宅 · 火天大有变乾为天

- **出处**：《增删卜易》卷四·旧宅章第一百十三（维基文库本）

**原文**：

```
巳月己丑日占得大有之乾卦
官鬼巳火⚊应 父母戌土⚊
父母未土ㄨ 兄弟申金⚊
兄弟酉金⚊ 官鬼午火⚊
父母辰土⚊世 父母辰土⚊
妻财寅木⚊ 妻财寅木⚊
子孙子水⚊ 子孙子水⚊
断曰：世为本宅，庙为应，世应相生如何有犯？庙前另有一物，未土发动刑世，乃此故耳。彼曰：庙前有一照壁，照壁之后有一株大树，数百年矣。予曰：即此物也。尔用大兽头安于尾脊，张口对树则吉。
```

**编者按**：此例是「以卦取象断宅」的示范：世为本宅、应为庙，世应相生本无犯；未土发动刑世，故断「庙前另有一物相犯」——果有照壁与大树。要点：家宅卦以世为宅、父母为屋、官鬼为犯；取象要落到具体方位物事，但仍以生克刑冲为骨。

## 例十八　占地 · 山雷颐变天雷无妄

- **出处**：《增删卜易》卷四·寻地章第一百十九（维基文库本）

**原文**：

```
寅月戊午日占地得颐变无妄卦
兄弟寅木⚊ 妻财戌土⚊
父母子水ㄨ 官鬼申金⚊
妻财戌土ㄨ世 子孙午火⚊
妻财辰土⚋ 妻财辰土⚋
兄弟寅木⚋ 兄弟寅木⚋
父母子水⚊应 父母子水⚊
断曰：世爻戌土，春天休囚，化出午火子孙回头生世，日月世爻其成三合，青龙戏水，以化长生，水源极远，只因申为月破，戌土克子水，又被日神冲散，春夏有水，秋冬必动。彼曰：正是如此。予曰：不妨，不可求全责备，卦中日月世与子孙共成三合，死者安而生者乐，子孙昌盛，何愁不发，后竟葬之，辰年下葬，酉年孙中亚魁，及至子年，次孙又登乡榜。
```

**编者按**：此例是「三合」与「化回头生」的合看：世爻戌土春月休囚，化出午火子孙回头生世，日、月、世与子孙又成三合，故断「死者安而生者乐」，后孙辈连中。要点：一爻得回头生、又入三合局，衰可转旺；占地看「气脉」，不只看一时旺衰。

## 例十九　占附葬 · 地雷复变坤为地

- **出处**：《增删卜易》卷四·新亡附葬祖茔章第一百三十（维基文库本）

**原文**：

```
如子月丙申日占以父柩附葬祖苗得复之坤卦
子孙酉金⚋ 子孙酉金⚋
妻财亥水⚋ 妻财亥水⚋
兄弟丑土⚋应 兄弟丑土⚋
兄弟辰土⚋ 官鬼卯木⚋
官鬼寅木⚋ 父母巳火⚋
妻财子水○世 兄弟未土⚋
断曰：世爻被克，不宜附葬之。后仍附葬。数月后不断曰：腰疼欲死，欲迁其坟。予曰：坟不必迁，卦中世爻被克，幸而旺相，土来克水，命道安土神则吉，果于安坟而愈。予曰：目下虽不迁改，终有迁改。彼曰：何也？予曰：化六冲不久之象。果于子年死母，起此冢合葬于他处也。
```

**编者按**：此例讲「化六冲」：世爻被克，先断不宜附葬；后仍附葬而致腰疼，再占调治，终以「化六冲不久之象」断必有迁改，后果迁葬。要点：卦变六冲主「不久、必变、终散」，用于宅墓则主不能久安；断事须留后验，不可一次占断即了。

## 小结：《增删卜易》断法的几条要义

1. **先取用神，再论生克**：用神一错，全盘皆错。上举诸例，几乎每一例的第一句话都是「以某爻为用」。
2. **月建日辰为主宰**：月建管一月的提纲，日辰管当下的主宰；月破、日冲、暗动、旬空皆由此出。
3. **动必有因，变见结果**：动爻是事情的发端，变爻是结果与回头之力；化进、化退、化空、化墓、回头生克，皆在变爻上见。
4. **不轻断，重再占**：疑而不决则命之再占，两卦互参——这是《增删卜易》区别于坊本的重要态度，也是「不妄断」的体现。
5. **旺衰为底，象为衣**：六神、卦名、物象都作佐参，主断仍在旺衰生克；旺相逢冲是冲起，衰休逢冲才是冲散，不可倒置。
6. **留验证，肯改错**：原书屡见「后悟」「始悟」「予试之不验，不以为法」，断卦者须记录、复盘、自我修正。
