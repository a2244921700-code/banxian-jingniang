# 三式与五门择用

**先做**：不论用哪门，先调 `gua_now` 取时取地（真太阳时、农历干支、节气、经纬度）；五门都吃这一套时间基准，先后不一就会自相矛盾。

**名实先分清**：传统「三式」是奇门、太乙、六壬；本 Agent 三式齐备，另加梅花、六爻，共「五门」——梅花、六爻、奇门、六壬、太乙。太乙另有专篇 `guashi-taiyi`，断时先 `gua_taiyi` 出盘（mode 取时计/日计/月计/年计）。

## 一、择用决策表（何事用何门）

| 所问 | 首选 | 次选或旁证 | 理由 |
|---|---|---|---|
| 快速定象、突发事、外应明显 | 梅花 | 六爻 | 起卦最便，重体用与外应 |
| 一事成败、求财、婚恋、官讼、疾病、寻人、失物、考试 | 六爻 | 梅花（取象）、六壬（过程） | 六亲用神最细，能定应期 |
| 方位、择时择方、出行、房宅、大事格局 | 奇门 | 六壬（过程） | 九宫八门主方位时空，善择优 |
| 人事来意、多方关系、官讼、寻人 | 六壬 | 六爻（成败） | 四课三传见始中终 |
| 问大局、年运、国事、长周期、主客胜负 | 太乙 | 奇门（方位）、六壬（过程） | 太乙积年九宫、主客算、八将计神宜论大事 |
| 只问「成不成」、时间紧 | 六爻或梅花 | — | 一卦一断，快 |
| 问「何时何方位去办」 | 奇门 | — | 择时择方是奇门本行 |
| 只有数字或时间、无实物 | 梅花 | — | 时间卦、数字卦最省事 |
| 用户已指定某门 | 从其所指 | — | 尊重问者所信，不擅改门 |

定门前先问三件事：**一问所问是成败、方位、过程还是大局**，**二问事之远近**，**三问用户有无指定**。拿不定时按「有无明确用神」定：有则六爻，无则梅花；论大局取太乙。

## 二、五门各自主轴（差异记牢才不混）

| 门 | 起课工具 | 主轴 | 不擅长 |
|---|---|---|---|
| 梅花易数 | `gua_cast`（meihua_*） | 体用生克、互变、外应 | 细人事、长久应期 |
| 六爻 | `gua_cast`（liuyao_*） | 六亲用神、日月旺衰、动变 | 方位、大局 |
| 奇门 | `gua_qimen` | 九宫方位、门星神、格局克应 | 六亲细节、私情 |
| 六壬 | `gua_liuren` | 四课三传、天将、课体 | 明确方位与择时 |
| 太乙 | `gua_taiyi` | 积年九宫、十六神八将、主客算 | 私事细碎、日常小占 |

口诀：**无头绪取梅花，问得失取六爻，问方位取奇门，问人事取六壬，问大局取太乙；一门主断，余门作参。**

五门古籍依据：梅花重体用（《梅花易数·体用总诀》），六爻重六亲生克（《黄金策·千金赋》），奇门重方位克应（《烟波钓叟歌》），六壬重四课三传（《六壬大全·毕法赋》），太乙重积年主客（《太乙金镜式经》）。

白话：三式＝奇门、太乙、六壬；五门＝本 Agent 的梅花、六爻、奇门、六壬、太乙；混断＝把一门的符号硬套到另一门上。

## 三、五门互参原则（避免混断）

1. **一门定主断，余门只作旁证**：按第一节表定主场，主场出结论；参门只校方向、时间、方位。
2. **不移植符号**：奇门宫位≠六爻爻位；六壬天将≠六爻六神；梅花体用≠六爻用神；十干克应只属奇门，课体只属六壬。
3. **不拼盘**：不把两门结果「取长补短」拼成第三种断语；两门相左时如实说明分歧，并说更信哪门及理由。
4. **一次一问**：同一问题不连起多门、反复起卦；要补信息，就问一个更具体的子问题。
5. **分别取用**：每门各按本门取用神（六爻取六亲、奇门取宫与门星神、六壬取日干三传、梅花取体用），不得借别门取用。
6. **应期不混**：六爻用空填、冲合，奇门用宫数、宫支，六壬用三传，梅花看卦气与外应；哪门出应期就标哪门。

## 四、合参示例

**例一：问财（主六爻，奇门参方位与时机）**

1. 六爻：以妻财为用神，看财爻旺衰、子孙（财源）是否生财、兄弟（劫财）是否发动、世应关系 → 定「成不成、财多财少」。
2. 奇门：看生门、戊（资本）、日干落宫，看生门宫与日干宫生克旺衰 → 定「财在何方、何时较顺」。
3. 合：以六爻断成败与应期为主，奇门方位时机为辅。两门相左时如实说「卦象主成、奇门方位不利，宜守原处待时」，不下绝对断语。
4. 记档：`gua_case` 记问题、两门盘、判断与关键点，标「主六爻、参奇门」。

**例二：问行程（主六爻或六壬，奇门参方位，梅花看外应）**

1. 六爻：出行以世爻为自身、应爻为目的地，父母为车船文书、官鬼为阻碍，看世应生克与动爻冲克 → 定「成行与否、顺逆」。
2. 六壬：看四课三传与驿马，初传为起程、末传为到达，天将定途中情状 → 补「过程与应期」。
3. 梅花：起卦时若恰有外应（见车、见雨、闻声），以体用与外应佐象。
4. 奇门：问「往何方、何时动身」时，看所往方位宫的门星神吉凶与马星 → 定方位与时辰。
5. 合：主门定成行，参门补过程方位；输出标清各门各断什么，并 `gua_case` 记档。

## 五、常见错法

1. 拿六爻断方位、拿奇门断六亲细节（越界）。
2. 两门结果不同就混成一句「可能成可能不成」——应说清分歧与更信哪门。
3. 一个问题上四门，信息过载、互相矛盾。
4. 把「三式」当成梅花、六爻、奇门（三式是奇门、太乙、六壬，无梅花六爻）。
5. 忘了先 `gua_now`，各门时间基准不一致。
6. 用户点名某门还擅自换门。
7. 合参后不用 `gua_case` 记录，无法复盘。
8. 拿太乙断日常琐事（太乙宜论大事大局；小事用梅花六爻即可）。
