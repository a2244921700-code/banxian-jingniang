# 起卦总则

## 〇、第一步永远是取时取地

任何起卦、起课之前，先调 `gua_now` 取时取地：

- 用户说了地点：`gua_now({location:{city:"杭州"}})`；已知经纬度就直接传 `latitude`、`longitude`。
- 用户没说地点：`gua_now({})` 自动定位。若返回的 `location.source` 是 `config` 或 `none`，必须向用户明说「定位失败，暂按配置默认地点算；时辰不受影响，但方位类判断要打折扣」。
- 从返回的 `almanac` 取四柱、月建、节气、真太阳时、`hourBranch`，后面所有断语都以它为时间基准，**不要自己心算干支**。

白话：**取时**是定年月日时四柱、节气月建；**取地**是定经纬度、真太阳时与方位。时辰差一位，卦就可能全变。

## 一、五门选法决策表

| 所问之事 | 首选 | 理由 | 备注 |
|---|---|---|---|
| 一时兴起、突发外应、寻物、问应期、日常小事 | 梅花易数 | 一物一数即可成卦，重取象与体用，最快 | 最常用；有外应时优先 |
| 问财、官、病、婚、讼、失物，且要看得细 | 六爻 | 有世应、六亲、六神、旬空、月破、动变，层次最全 | 传统「问事」主力 |
| 问方位、出行、谈判、谋事成败、找方向、看格局 | 奇门遁甲 | 九宫八门九星八神定位，长于断方位与时机 | 一事一局，时家为主 |
| 问大势、人事纠葛、消息真假、官讼、远方、多方参与 | 大六壬 | 四课三传、十二天将，长于推演人事与过程 | 重「人谋」与来龙去脉 |
| 问年度大势、国事政商大局、竞标竞聘、主客胜负、兵争诉讼大局 | 太乙神数 | 积年九宫、十六神八将、主客算，古法专论大事 | 日常小事不必起太乙 |
| 用户已指定法门 | 从其指定 | 尊重问者所信，起卦本身要诚 | 不擅改门 |
| 拿不定主意 | 梅花易数 | 门槛最低、上手最快 | 或按「有无明确用神」定：有则六爻 |

术语一句话：**用神**是一卦中代表所问之事的那个爻；**旬空**是日柱这一旬里轮空的两个地支，象「暂时落空」。

口诀：**无头绪取梅花，问得失取六爻，问方位取奇门，问人事取六壬，问大局取太乙。**（五门互参与避免混断，见 `guashi-sanshi`）

## 二、起卦前必做四件事

1. **取时取地**：见第〇节，先 `gua_now`。
2. **让用户明确「一问」**：把话收成一句「何人、何时何地、问何事、求何结果」。例：用户说「我想问今年能不能考上公务员」——主体是你，事体是考试录取，时限是今年，这才够起卦。若一句话里问三件事，回问只取一件；都要问就分三次起卦。
3. **诚敬**：古法有「初筮告，再三渎，渎则不告」（《周易·蒙》卦辞）——第一次问就告诉你，反复问是把占卜当儿戏，亵渎了便不再告。操作上：一事一卦；不得因结果不合心意就换门重起；确需复核，须明说是「复核」，并换角度另设一问。《周易·系辞上》又把「以卜筮者尚其占」列为圣人之道四之一——占是正经学问，问者与断者都不该轻慢。
4. **定门**：按决策表选定一门，起卦前向用户说明「这一问用某门」，再起。

## 三、参数怎么填

**梅花·时间卦**：`gua_cast({method:"meihua_time", question:"……"})`。一般不给 `datetime`，用当下；若事情以某个时刻为准（如「明日九点签合同」），传 ISO 字符串，并在断语里点明「以该时为起卦时」。

**梅花·数字卦**：请用户随口报 2 个或 3 个数，`gua_cast({method:"meihua_number", numbers:[7,3,2]})`。两数依次为上卦数、下卦数；三数则第三数定动爻。卦数用先天数：1乾 2兑 3离 4震 5巽 6坎 7艮 8坤；数过 8 除 8 取余，余 0 作 8；动爻数过 6 除 6 取余，余 0 作 6。

**梅花·物数/字数卦**：数物件、字数、人数、声响次数，填 `gua_cast({method:"meihua_count", counts:{upper:…, lower:…, moving:…}})`。起完先看返回的 `cast.detail` 与 `hints`，确认取卦取爻合古法「余 0 作 8 / 作 6」；若不合，改用 `numbers` 或 `upper`+`lower`+`moving` 显式指定。

**六爻·摇钱**：请用户三枚铜钱摇六次，自下而上记录，`gua_cast({method:"liuyao_coins", throws:[…]})`。每爻可填数字（6 老阴、7 少阳、8 少阴、9 老阳），也可填三枚正反（如 `"正正反"`；正＝阳＝3、反＝阴＝2，三枚之和即 6/7/8/9）。用户不便摇钱，可用 `method:"liuyao_random"`，但要诚实说明是随机数模拟，不必假称手摇。

**六爻·已有卦**：把上下卦与动爻交给 `gua_cast({upper:…, lower:…, moving:…})`；只知卦名，先用 `gua_hexagram` 查出 `binary` 与上下卦。

**奇门**：`gua_qimen({question:"……"})`，默认时家转盘 + **拆补法**定局（现代主流排盘常用）；要按古法置闰可传 `juMethod:"置闰"`，并在断语里说明用的是哪一法（两法定局个别时刻差一局）。问方位、找物、出行可传 `datetime`。**六壬**：`gua_liuren({question:"……"})`，昼夜自动判定（卯酉分界），夜间课可显式传 `daynight:"夜"`。**太乙**：`gua_taiyi({question:"……", mode:"时计"})`；问年度/长期大势用 `mode:"年计"`，问某日之事用 `日计`，问本月用 `月计`；起完先看返回的 `ju`、`taiyi`、主客算与 `hints`，再按 `guashi-taiyi` 断。

**子时换日**：引擎已按传统把 23:00–23:59 算作**次日**（子时为新一日之始），日柱、农历日、晚子时时干一并进位；`gua_now` 的 `almanac` 会标 `enteredNextDay` 与 `effectiveDate`。断语说「今日/明日」时按这个日界，不要按 0 点算。

**定时的三条硬规矩**：① 以问事当下为准；② 问已发生之事，用事发时刻；③ 时间一旦填定，起后不得改时重排——改时等于重起，犯「渎」。

## 四、起完就记录

用 `gua_case` 的 `record` 落档，越详细越有用：

- `question`：原话照录，不要替用户改写；`method`：如实填 `meihua_time` 等。
- `ben`/`bian`：本卦、变卦名；奇门、六壬填课局名（如「阴遁五局」）。
- `judgment`：结论＋应期＋「可做的事」，一段话写完。
- `keyPoints`：3–5 条关键依据（如「用生体、月建戌土、动爻在三」）。
- `tags`：求财、婚姻、考试、出行等；`followUpAt`：预计应验的日期。

事后再用 `gua_case({action:"update", caseId:"…", outcome:"…", verified:true})` 回填结果。用户说「上次那卦」时，先 `gua_case({action:"list", query:"关键词"})` 或 `gua_history({action:"search_sessions", query:"…"})` 取证，绝不凭印象编旧卦。

## 五、常见错法

| 错法 | 后果 | 正办 |
|---|---|---|
| 不澄清就起卦 | 卦对不上事，全盘白断 | 先问清「一问」 |
| 一事多起、换门重起 | 犯渎，越起越乱 | 一卦为凭，复核须明说 |
| 自己先有结论再挑卦 | 是「验卦」不是「占卦」 | 起后只看盘面 |
| 拿北京时间直接当真太阳时 | 时辰可能错一位 | 用 `gua_now` 的 `trueSolarTime` |
| 断生死、替代医疗/法律/投资判断 | 越界且伤人 | 改成「风险提示＋可做的事」 |
| 起完不记录 | 无法复盘，前后矛盾 | 当场 `gua_case record` |
