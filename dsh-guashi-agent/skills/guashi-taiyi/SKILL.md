# 太乙神数断法

太乙与奇门、六壬合称三式。奇门重方位，六壬重人事，**太乙重积年大数与主客胜负**，古法多用于兵事、国事、年岁丰歉。断太乙先读盘，不心算积年。

## 0. 先取时取地

凡涉时辰、方位，**先调 `gua_now`**：取当前时间、农历干支、节气、真太阳时与所在地（定位失败时按默认地点并说明）。太乙「四计之中时计尤要」（《太乙金镜式经》卷一），时计须用真太阳时。

## 1. 起盘与计别

调 `gua_taiyi` 出盘，传 `datetime` 与 `mode`：

| 计别 | 何时用 | 依据 |
|---|---|---|
| 时计 | 即时应事、问眼前成败 | 四计中时计尤要（卷一） |
| 日计 | 问近日、数日之内 | 师尹用日计（卷二「推太乙用式不同法」） |
| 月计 | 问月内、一季趋势 | 卿士用月计（同上） |
| 年计 | 问一年、国事、组织大势 | 王者用岁计（同上） |

盘面按语义读：太乙落宫、文昌、始击、计神、主大将、主参将、客大将、客参将、九宫各宫星神与 `hints`；引擎若给出主算、客算、定算与格局提示，一律据盘面数值断。**工具没给的数值不臆补**，在回复中说明缺项。

## 2. 用神取法

| 所问 | 取用神 |
|---|---|
| 自己/主方/大局主导 | 太乙（监将） |
| 己方谋略、文书、主帅 | 文昌（主目、下目） |
| 对方/客方/外部变动 | 始击（客目、上目） |
| 策划、算计、暗中筹谋 | 计神 |
| 双方实力与执行 | 主大将／主参将（己方）、客大将／客参将（对方） |
| 主客强弱 | 主算（主方之势）、客算（客方之势） |

出处：《太乙金镜式经》卷二「推五将所主法」——五将者太乙监将、上下二目、主客大小将；上目始击属客，下目文昌属主。问组织大事兼看年计与太乙宫；问具体应事以时计为主，看文昌、计神。

## 3. 主客算吉凶

- **算长势厚，算短势薄**；主客两算相较定强弱。
- **阴阳和则吉，不和则凶**：阳宫得奇、阴宫得偶为和；重阳、重阴皆不和（卷二「推阴阳和不和」）。「算和者利，不和者谋不成」（卷三「推囚法」）。
- **三门具、五将发**（开休生三吉门,始击无掩击、文昌无囚迫、主客大小将无相关）则可举事；三门不具、五将不发宜固守（卷四「推三门具不具」「推五将发不发」）。
- **先后之辨**：先动为客、后应为主；得三门具五将发、阴阳和者，兵所向必克（卷四「推主客」）。

## 4. 格局（《太乙金镜式经》卷三）

| 格局 | 定义 | 断意 |
|---|---|---|
| 掩 | 始击临太乙宫 | 暗算压制、君弱臣强，宜修德禳之 |
| 击 | 客目在太乙前后一辰/一宫 | 以下犯上、被侵凌 |
| 迫 | 二目及主客大小将在太乙左右 | 近身胁迫；辰迫急、宫迫缓 |
| 囚 | 文昌与诸将同太乙宫 | 束缚、谋难成；算和者利 |
| 关 | 主客将目相宫齐 | 相持、将相猜忌 |
| 格 | 客目、大小将与太乙对宫 | 乖违、盗侮其君，算不和必败 |
| 对 | 文昌与太乙冲 | 对峙、二心 |
| 四郭固／郭杜／执提／提挟 | 卷三有专条 | 谋事闭塞、不利先起 |

凶格不必即凶：算和、门具将发可减；吉格失令亦难成。「凶格有制可解，吉格失令难成」。

## 5. 克应与应期

- 取象：太乙为君/主导者/大势；文昌为主方谋略、文书、主帅；始击为对方、变动、外患；计神为谋划算计；主大将、客大将各为双方实力与执行。
- 古法克应看**方位、旗色、阵形、云气、伏兵时**：《太乙秘书》每局断语如「利为客，见阵利先动，出军宜东北，战利西南，利直阵，举青旗，云气从北来，客胜，闻贼备西南」——现代可化用为：宜行之方、宜取之势（先动/后应）、宜进宜守、外应之兆。
- 外应：《太乙金镜式经》卷四「推风云飞鸟助战法」——风云鸟兽从某方冲格太乙或大将宫者，为败兆；扶主阵则主胜。占时所见异常可作旁证，不作主断。
- 应期：时计以时辰，日计以日，月计以月，年计以年；远事用年计、近事用时计。应期不明时给区间与可观察之兆，不硬断时刻。

## 6. 与奇门、六壬互参

- 问方位趋避、择时出行 → 奇门（`gua_qimen`）；
- 问人事过程、对方心思、类神 → 六壬（`gua_liuren`）；
- 问大势、主客胜负、国事兵事 → 太乙（`gua_taiyi`）。
可同题合参：两式一致处以之为断，矛盾处说明分歧与所据，**不混用术语**（太乙有五将十六神，奇门有八门九星，六壬有天将四课，各成体系）。古籍原文可经 `gua_kb` 检索（本库 `10-太乙神数`，书名为《太乙金镜式经》《太乙秘书》），引用注篇卷。卦案用 `gua_case` 记录：问事、计别、盘面要点、判断与应验。

## 7. 输出与边界

结论先行、现代汉语为主；文言术语随手解释；给「可行之路」。太乙古法重兵事国事，现代问个人宜降格为趋势与宜忌并说明；不决生死，不代医疗、法律、投资判断。

## 8. 常见错法

- 用农历年直接算太乙（须积年、周纪、元法、小周逐层除）。
- 计别混用：拿年计断当天小事，或时计断十年大势。
- 把奇门八门、六壬天将硬套太乙盘（太乙自有五将十六神与主客算）。
- 见「掩迫囚格」即断大凶，不看算和、门具将发。
- 凭空写主算客算数值：必须读 `gua_taiyi` 盘面；缺项要说明。
