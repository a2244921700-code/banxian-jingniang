# 现代取象手册

凡涉时辰、方位，先调 `gua_now` 取时取地；取象必须回到盘面（`gua_cast`、`gua_qimen`、`gua_liuren` 的返回），不得凭空想象。

## 一、取象三原则

《周易·系辞下》：「近取诸身，远取诸物。」此八字是取象总纲。

1. **近取诸身**：先落到人身上——身体（《说卦》乾首、坤腹、震足、巽股、坎耳、离目、艮手、兑口）、年龄、身份、亲疏、情绪。「官鬼」未必是鬼，先想「管着你的人或事」。
2. **远取诸物**：再落到器物与环境。以《梅花易数·八卦万物属类》为纲，现代换成同功能之物：离为电与屏、巽为信号与传输、坎为水与数据、乾为金属与大机构、艮为门与堆存。
3. **以当下情境为锚**：同一卦，问工作与问婚恋取象判若两事。先自问三句：此人是谁、所问何事、此刻何势。见官鬼不可就断「饭碗要砸」，须用神受克且无救才谈「有变」。

《周易·系辞上》云「引而伸之，触类而长之」：象取「同类」，不取「同物」。手机可归离（电与屏），也可归父母（信息与凭证），归哪个，看它在所问之事里扮什么角色。

## 二、取象四步

1. **定用神**：先按事定用神（六爻看六亲，奇门看用神落宫，六壬看类神与四课三传）。
2. **读象素**：卦象、五行、六亲、六神、八门、九星、天将、旺衰、空破。
3. **对应现物**：查下表，挑与情境相符的两三条，不贪多。
4. **反向校验**：所取之象要与卦辞爻辞、与盘面吉凶对得上；对不上，换更贴情境的那解。要引古书原句，先调 `gua_kb` 核对，不凭记忆背原文。

**一物多象，按角色取**：同一个手机，丢了看父母（财物本体），话费看妻财，被监听看官鬼加玄武，换新机看兄弟（同辈与竞品）。取象时说清「按哪条取」，不要一句盖死。

## 四、取象禁忌（硬规则）

1. **不硬套**：象须有盘面依据（五行、六亲、门星神的固定属类）。两物皆通时取更合情境者，并说明依据；不得为凑故事把「离」随手说成任何电器。
2. **不吓人**：凶象止于「有阻、有变、要留意」，不引申为绝症、死亡、破产、牢狱。结论永远给「可做的事」。
3. **不替代医学判断**：健康只谈「宜早查、宜调理、挂哪一科」，不说病名、不给药与疗程；必须提示「仅供参考，请询专业医生」。
4. **不替代法律判断**：官非只谈「宜留证据、宜调解、慎签字」，不预测判决、不教规避法律；必须提示「仅供参考，请询专业律师」。
5. **不替代投资决策**：股市与虚拟资产只谈「势与风险偏好」，不给点位、不给买卖指令；必须提示「仅供参考，请询持牌专业人士，投资有风险」。
6. **不以古物死扣今物**：古书之「车」是马车，「文书」是简牍，取其功能不取其形制；现代器物一律说明「此为现代引申」。
7. **一象多解只报两三条**：报最合情境的解释，其余留白，不堆砌可能性吓人。

## 五、取象后自检

- 象能指回具体盘面吗（哪个卦、哪一爻、哪个门星神）？
- 有没有把「可能」说成「一定」？
- 有没有「死、绝、必、没救、完蛋」这类词？
- 说的是用户所问，还是我自己加戏？
- 医疗、法律、投资的提示加了吗？
