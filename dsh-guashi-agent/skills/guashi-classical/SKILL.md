# 读古籍的方法

## 一、先看序与凡例

拿到一本古籍，别从正文第一行硬啃：

1. **看序**：作者自序交代写作缘起、时代、师承与立场；后人序跋常带版本与真伪信息。序里往往藏着「这本书要解决什么问题」。
2. **看凡例**：体例说明——收什么、不收什么、怎样编次、术语怎么用。凡例是作者自己下的定义，比后人解释可靠。
3. **看目录**：先弄清全书骨架，再挑要用的篇章读，不必从头读到尾。
4. **看版本**：术数书版本杂、托名多，同名的书可能内容大异。见「旧题某某撰」要留一分疑心；拿不准就说明「此书旧题某人，成书年代存疑」。

例：《四库全书总目·子部·术数类》的小序梳理术数源流与分类，先看它，能知道一本书在传统目录里属哪一类、地位如何。白话：**序与凡例是作者留的说明书，先读能省一半力气。**

## 二、术语先定名

术数最怕同名异义。同一个词，在不同书、不同门里常不是一回事：

| 词 | 常见义一 | 常见义二 |
|---|---|---|
| 体用 | 梅花：不动卦为体、动卦为用 | 义理易：本体与作用 |
| 用神 | 六爻：一卦中代表所问之事的爻 | 奇门：所测人事对应的宫与干 |
| 应期 | 梅花：以卦数卦气推时日 | 六爻：用神值日、冲合之期 |
| 旬空 | 六爻：日柱一旬中轮空之支 | 六壬：旬中空亡之支 |
| 月建 | 节气所定之当月地支 | 农历月份地支（两者不同） |

做法：**读到一个词，先在本书记下它的定义，再读别书**；遇冲突以「本书义」为准，并在输出里注明「此处依某书之义」。白话：**定名就是先跟作者对暗号，暗号不对，后面全读歪。**

## 三、异体字、通假字、避讳字

- **异体字**：同字异写，如「無／无」「氣／气」「說／说」。保留原字，括注今字即可。
- **通假字**：借音表义，如「说」通「悦」（《周易·说卦》「兑，说也」，即兑为悦）、「咸」通「感」（《周易·咸·彖》「咸，感也」）。判断靠古音，不靠字形。
- **避讳字**：清刻本避康熙讳，常把「玄」写作「元」。所以术数书里「元空」「元机」有时实为「玄空」「玄机」，读时须还原。
- **繁简转换**：机器转简最易出错，典型是「乾」被转成「干」——「乾为天」不能变「干为天」，「乾隆」也不作「干隆」。凡见卦名、干支、书名，一律回查原文。

白话：**字形会变，字义有根；认得根，才不被纸面骗。**

## 五、训诂三法

训诂就是**解释古书字义**。三法要合看，不能只用一法：

1. **形训**——看字形说义。《说文解字·叙》「盖文字者，经艺之本，王政之始」；《说文解字》释「卜」为「灼剥龟也，象灸龟之形」，从字形可见卜是烧灼龟甲取兆。白话：**拆字看它本来画的是什么。**
2. **声训（因声求义）**——古音相同相近则义常相通，用来破通假、寻同源。清代王念孙《广雅疏证》主张因声求义；经传自身的声训如《周易·咸·彖》「咸，感也」、《周易·说卦》「兑，说也」。白话：**读起来像，意思往往也通。**
3. **义训**——用今语释古语、用通名释别名。《尔雅·释诂》开篇「初、哉、首、基、肇、祖、元、胎、俶、落、权舆，始也」，用「始」一义统摄十一词。白话：**用现在的话说清楚它是什么意思。**

操作四步：**查旧注**（王弼注、孔颖达疏、朱熹《周易本义》等）→**对字书**（《说文》《尔雅》《广韵》）→**依文定诂**（据上下文取最通的一义，不取最巧的一义）→**落成白话**（一句说完，不堆术语）。

## 六、引文规则

写回复时引古籍，照这七条：

1. **非必要不引**：关键处引一两句即可，通篇典故反而看不清。
2. **必注出处**：书名＋篇名，如《周易·系辞上》《梅花易数·体用总诀》。
3. **引一句，解一句**：引文后紧跟白话，用破折号或「意思是」带出。**没有白话解释的引文，等于没引。**
4. **短引**：一两句、约二十字为度，不整段搬。
5. **不改字**：异体、通假保留原样，需要时括注今字。
6. **不编原文**：记不准就不引，改写成「某书大意是……」并说明是概述；宁可概述，不可伪引。
7. **术语首见必释**：如「旬空——日柱这一旬里轮空的两个地支」，一句白话即可。

**正例**：《周易·系辞上》「君子居则观其象而玩其辞，动则观其变而玩其占」——平居时看卦象、琢磨卦爻辞，行动时看变化、玩味占断。

**反例**：「《系辞》云：动则观变。」——出处不全、删改原文、没有解释，三样都犯。

## 七、常见错法

| 错法 | 说明 | 正办 |
|---|---|---|
| 望文生义 | 把「潜龙勿用」解成「龙没用」 | 查小象「阳在下也」，是暂不施展 |
| 以今义解古义 | 「消息」当新闻、「经济」当钱财 | 消息＝消长，经济＝经世济民 |
| 以注代经 | 把朱熹注当经文引 | 经是经、注是注，分开标 |
| 版本不问 | 托名之书当信史 | 说明旧题与存疑 |
| 繁简误转 | 乾→干、後→后 | 卦名干支回查原文 |
| 引而不解 | 甩一句文言就走 | 一句白话跟上 |
