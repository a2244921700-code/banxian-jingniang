# 紫微斗数断法

**先做**：调 `gua_now` 取「此刻此地」（当前时间用于定「当前大限/流年」，也用于核对时区地点）。再问清**出生三件套**：①公历出生年月日与时（几点几分，子时口径见下）；②性别（决定大限顺逆）；③出生地（真太阳时/子时判界；不确定就用配置默认地点并说明）。三件套缺一不可，缺则先问，不猜。

然后用 `gua_ziwei` 排盘：返回 `meta`（命宫/身宫/五行局/命主身主/四柱/大限/流年）、`palaces`（12 宫：主星+庙旺+四化、辅星六煞、宫干支、大限、流年命宫、神煞）、`details`、`hints`。查古籍与格局用 `gua_kb`（book 填「紫微斗数全书」「紫微格局大全」）；断毕用 `gua_case` 记档（问事、盘面摘要、断语、应期、标签）。

「大抵人命俱从寅上起正月，顺数至本生月止，又自人生月起子时逆至本生时安命，顺至本生时安身。」（《紫微斗数全书·安身命例》）白话：命宫以生月与生时定，身宫把「逆」改「顺」；这一步引擎已算好，不要自己再排。

## 一、读盘六看（按顺序，不跳步）

1. **命宫 + 身宫**：命宫看先天性情与格局，身宫看后天着力点（身宫落夫妻则重感情婚姻，落财帛重财，落官禄重事业）。
2. **三方四正**：本宫、对宫（地支隔六位）、两个三合宫（隔四位、隔八位）。**任何一宫都不能只看本宫**；命宫的三方四正就是命、财、官、迁（外加对宫与三合，落到实际宫位以盘面地支为准）。
3. **十四主星与庙旺**：庙旺平陷决定星力强弱；庙旺吉星加分，落陷吉星减分，落陷煞星更忌。
4. **四化落宫**：先看生年四化落在何宫、何星；再看大限、流年四化（引擎暂只排生年四化，限运四化需说明另议）。
5. **煞忌与吉辅**：羊陀火铃空劫、化忌、天刑天姚为破格与风险；左辅右弼昌曲魁钺禄存天马为助力。煞忌不是见之即凶，要看落在何宫、有无制化。
6. **格局**：查 `知识库/12-紫微斗数/紫微格局大全.md`，取最贴切的**一至两格**，不堆名单；注意破格条件。

## 四、四化象义与落宫

| 四化 | 本义 | 吉/忌 |
|---|---|---|
| 化禄 | 得、缘、财、顺、享受 | 吉；入财官田宅最喜 |
| 化权 | 掌权、掌控、争、变 | 吉（带压力）；入官禄命宫有力 |
| 化科 | 名声、贵人、文书、考试 | 吉；入命、官、迁移显名 |

落宫简断：入命宫 → 一生所执；入兄弟 → 平辈缘；入夫妻 → 感情牵绊；入子女 → 子女/创作；入财帛 → 求财方式；入疾厄 → 身心注意；入迁移 → 外出际遇；入交友 → 人际是非；入官禄 → 事业起伏；入田宅 → 家宅；入福德 → 心境；入父母 → 长辈文书。

## 五、大限与流年

- **大限**：每宫十年，顺序由阳男阴女顺行、阴男阳女逆行（引擎 `details.daxianDirection` 已给）；大限宫位是这十年的「舞台」，大限主星与生年四化落此限者为题。
- **流年**：流年命宫取该年地支宫（引擎已标 `liunian: '流年命宫'`）；流年四化、流年斗君等进阶项引擎暂未排，需在断语里说明「流年细盘另议」，不可硬编。
- **应期**：以宫位地支、四化落点、大限流年的引动为线索；给区间与「什么现象算应验」。用户回来复盘时再 update，不主动追问。

## 六、断盘七步（操作顺序）

1. 定命身：命宫主星、庙旺、生年四化。
2. 看三方四正：吉星助力、煞忌冲破，先定「格局高低」。
3. 看四化：生年四化落在哪些宫，定一生主题与得失。
4. 看大限：当前大限宫与原局哪一宫重叠、引动什么。
5. 看流年：今年落在何宫，与命、大限的关系。
6. 查格局：`gua_kb` 查「紫微格局大全」，取贴切者一二，核对破格。
7. 落结论：先断势与路，再给可做之事与应期；`gua_case` 记档。

## 七、输出规范（与 guashi-output 一致）

- 现代汉语为主；术语随手用括号白话解释一句。
- **先盘后断**：先说盘面（命宫/身宫/五行局/主星庙旺/四化落宫），再说结论，再给可做之事。
- **不宿命、不吓人、不决生死**：不断寿元、不断疾病诊断、不判婚姻对错；健康只提醒就医，法律只提醒咨询律师，投资只谈风险偏好。
- 命理用于「认识自己、择时、取舍」，不是「改命」；不说「命该如此」。
- 篇幅按 `guashi-output`：一般 300–800 字起，可写足；不注水。

## 八、常见错法

1. 只看命宫主星，不看三方四正与对宫。
2. 见煞就断凶、见吉就断好，不看庙旺与制化。
3. 把格局名硬套（一个盘可有多格，也可能一格不入；不入格很正常）。
4. 忽略性别与阴阳顺逆，把大限排反。
5. 用一个命盘回答所有问题（事业问官禄、财问财帛、婚恋问夫妻，各归其宫）。
6. 拿现代书或旧歌诀的吓人断语直接转述（贫贱、夭折、克妻）。
7. 把流年当大限，或把生年四化当大限四化。
8. 手改盘面、凭记忆安星——盘面一律以 `gua_ziwei` 为准。

## 九、与前端/工具衔接

- `gua_ziwei` 的返回与 `client/ziwei-chart` 前端契约同构：`meta + palaces` 可直接 `ZiweiChart.render(result)` 出图。
- 盘面未实现项（流年斗君、小限、自化飞星、三方四正连线）在断语中如实说明；不得虚构。
- 命盘属个人隐私：卦案记录只记必要信息，不主动外传。
