# 六爻断法（纳甲）

**先做**：调 `gua_now` 取此刻真太阳时、农历干支、节气、月建、旬空与地点——六爻的旺衰空亡全赖这些，缺时不断。再用 `gua_cast`（method=`liuyao_coins`，或 `liuyao_random`）得盘：`lines` 已含纳甲、五行、六亲、六神、世应、空亡，`time` 已含日辰、月建、旬空。查原典用 `gua_kb`（book 填「增删卜易」「卜筮正宗」「黄金策」），查卦名变卦用 `gua_hexagram`；断毕用 `gua_case` 记档。

「动静阴阳，反复迁变；虽万象之纷纭，须一理而融贯。」（《黄金策·千金赋》）白话：卦象千变万化，断的始终是同一套生克之理。

装卦核对六项：①卦宫五行（六亲以卦宫五行为我：生我父母、同我兄弟、我生子孙、我克妻财、克我官鬼）；②纳甲干支；③六亲；④六神（按日干起）；⑤世应；⑥月建、日辰、旬空。盘中 `lines` 与 `time` 已给，缺卦象时用 `gua_hexagram` 补。

## 一、断卦硬顺序（逐条过，不跳步）

1. **一问**：问清何事、时限、求测者是谁；一卦只答一问。
2. **取用神**：按第二节表定「以哪一爻为我所问之事」。
3. **用神现否**：不上卦先取伏神（第七节）；两现取动者、旺者、临日月者，另一作旁证。
4. **日月定旺衰**：「日辰为六爻之主宰，月建乃万卦之提纲」（《增删卜易》月建、日辰二章）。用神得月生、日生、临日月为旺；被月冲为月破，被日冲而旺相为暗动。
5. **看旬空**：分真空、假空（第四节）。
6. **看动爻变爻**：动爻生克用神，变爻回头生克、化进退化空、动逢合冲（第五节）。
7. **看原神忌神仇神**：谁助用、谁害用、谁制忌（第三节）。
8. **看六神与世应**：定象、定人我（第六节）。
9. **定应期**：远近、合冲、填空（第八节）。
10. **落结论**：先断成败与势，再给「可做的事」；不决生死、不替医疗法律投资下结论。最后 `gua_case` 记档。

口诀：**一问二用三月日，四空五动六变，七忌八神九应期，末记卦案。**

白话：用神＝卦中代表所问之事的那个爻；旺衰＝得不得月建日辰之气；应期＝事可能落在何时；伏神＝用神不上卦时，藏在本宫首卦里的那一爻。

## 二、六亲取用表（《增删卜易·用神》，白话按现代生活补）

| 所问 | 用神 | 备注 |
|---|---|---|
| 自身之事（我在事中） | 世爻 | 世为我、应为对方 |
| 父母、长辈、老师、文书、契约、房屋、车船、衣服、信息 | 父母 | 考试以父母为文卷、官鬼为名次 |
| 官职、贵人、上司、丈夫或男友、疾病、官讼、盗贼、忧疑 | 官鬼 | 官鬼为病者，子孙为药 |
| 钱财、妻子、货物、薪资、饮食、工具 | 妻财 | 求财兼看子孙（财源） |
| 子女、晚辈、学生、医药、僧道、六畜、解忧 | 子孙 | 子孙为福神，亦克官鬼 |
| 兄弟、朋友、同事、同行、合伙、竞争者、阻隔 | 兄弟 | 兄弟劫财，亦主口舌阻隔 |
| 占他人 | 以其身份取六亲 | 身份不明取应爻 |

用神多现：取动、取旺、取临日月者，勿随手改取别爻。世应：世己应彼，世克应我强，应克世彼强；世空我心虚，应空彼不实。

## 三、原神、忌神、仇神

- **原神**：生用神之爻（问财，子孙生妻财）。
- **忌神**：克用神之爻（问财，兄弟克妻财）。
- **仇神**：克原神之爻（兄弟克子孙，既害财又断财源）。
- 断法：用神旺相、原神有力、忌神受制 → 吉；用神休囚、忌神发动克用、原神被伤 → 凶。忌神动而回头克、逢日冲、旬空，凶中可解。

## 四、旬空与月破

| 项 | 判据 | 断 |
|---|---|---|
| 旬空 | 爻支在 `time.xunKong` 或 `lines[].kong` | 空则虚、事多迟、人不实；旺相发动不空，待出旬、填实、冲空以实论 |
| 真空 | 休囚无气、无日月生扶、静而空 | 作无用论，事散 |
| 假空 | 旺相、发动、得日月生扶、动而化空 | 不以空断，待时而出 |
| 月破 | 月建冲爻（月建戌则辰爻破） | 力散；出月、逢日合、逢值可救，久事难成 |
| 暗动 | 日辰冲旺相静爻 | 静中忽动，事有意外之变 |
| 日破 | 日辰冲休囚静爻 | 冲散，作无力论 |

口诀：**空逢冲、逢填则实；破待合、待值则全。**

## 五、动爻、变爻生克冲合

| 变爻对本爻 | 象 | 断 |
|---|---|---|
| 回头生 | 变爻生本爻 | 后得助力，事有转机 |
| 回头克 | 变爻克本爻 | 先动后败；克忌神时反为吉 |
| 化进神 | 同五行顺支：亥→子、寅→卯、巳→午、申→酉、丑→辰→未→戌→丑 | 渐进而成 |
| 化退神 | 上列逆支：子→亥、卯→寅等 | 事渐退、力渐消 |
| 化空 | 变爻旬空 | 动而无实，虚应 |
| 化月破 | 变爻被月冲 | 事败中途 |

- 动逢六合为绊：事被牵住，应期看冲开之日；动逢冲：旺者冲起，衰者冲散。
- 多爻动者事多变，以用神所系为主；生克只论五行——变爻六亲诸家取法小异，不必死扣。
- 变爻干支若工具未直接给出，可把变卦上下卦交给 `gua_cast`（显式指定 `upper`、`lower`）重起一卦，取其 `lines` 干支。

## 六、六神取象（按日干起，盘中 `lines[].liushen` 已排）

| 六神 | 象义 | 常见事象 |
|---|---|---|
| 青龙 | 喜、贵、酒色 | 婚姻喜庆、贵人、宴饮、体面 |
| 朱雀 | 口舌、文书 | 文书信息、口舌官非、考试、消息 |
| 勾陈 | 土、迟滞、田土 | 房产田土、纠缠、官讼、拖拉 |
| 螣蛇 | 虚惊、怪异 | 惊扰、梦、虚耗、缠绕不清 |
| 白虎 | 凶伤、刚猛 | 伤病、丧服、争斗、道路 |
| 玄武 | 暗昧、盗 | 盗失、欺瞒、隐私、酒色 |

六神只助象、不定吉凶：吉神临凶爻仍从生克，凶神临吉爻亦然。

## 七、伏神（用神不上卦）

用神不上卦，是「事未成形」或「人不在明处」。取本宫首卦（八纯卦）中同一六亲之爻为伏神，压其上者称飞神。

- 伏神得日月生扶而旺、飞神生伏或飞神空破 → 可出、事可成。
- 飞神克伏、伏神休囚无气 → 伏而难出，事多阻。
- 出伏之期：伏神值日、飞神受制、冲开飞神之日。
- 八纯卦可用 `gua_cast({upper,lower})` 显式起出核对纳甲六亲。（《增删卜易·伏神》，取法亦见《易隐》）

## 八、应期（何时应）

- 近事应日时，远事应年月；旺相动爻速，休囚静爻迟。
- 用神值日、值月为应；旬空待填实或冲空；月破待逢合或出月；入墓待冲开；伏神待值日。
- 动而逢合应于冲日，动而被冲应于合日；静爻待冲、待值。
- 用神两现，以动者、旺者、临日月者定应期。
- 只给「可能时段＋快慢＋触发条件」，不硬报日子；拿不准就给区间。

## 九、常见错法（自查）

1. 一卦多问、换用神凑结论。
2. 不看月建日辰就先看动爻变爻。
3. 见空即断无、见冲即断凶（空有假空，冲有冲起冲散）。
4. 忌神发动却因六神吉而不忌；六神只助象。
5. 用神多现不辨动静旺衰。
6. 拿卦名、卦辞直接断成败（六爻以用神为主，卦辞只作参考）。
7. 断死断绝、替医疗法律投资下结论——只断势与可做之事。
