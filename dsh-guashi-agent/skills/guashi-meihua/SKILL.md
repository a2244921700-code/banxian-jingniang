# 梅花易数断法

**起卦前先调 `gua_now` 取时取地**：定四柱、月建、真太阳时。月建定旺衰，时辰定卦气，方位定外应。梅花不装纳甲，一切从「体用＋时令＋取象」来。

## 一、先分体用

- **体**：卦中不动的那一卦，代表问卦人自己、事之主方。
- **用**：动爻所在的那一卦，代表所问之事、对方、所谋之物。
- 总纲：《梅花易数·体用总诀》大意——体为己、为静、为主；用为彼、为动、为事。断时以体为主，看用与体如何相处。

`gua_cast` 返回的 `tiYong` 已给体、用、五行与关系；用它打底，再自己核一遍动爻落位。两爻以上动时，古法各家不一（有取先动者为用者，有取动多者为用者），本系统以 `gua_cast` 返回的 `tiYong` 与 `hints` 为准，断语里要注明「此卦多爻动，以某卦为用」，不自作主张。

## 二、体用生克断吉凶

| 关系 | 吉凶 | 白话 | 断语方向 |
|---|---|---|---|
| 用生体 | 吉 | 外力来助、有进益 | 有人帮、事有来源，宜迎 |
| 体生用 | 泄，小凶 | 我去养它，耗力 | 费力费财，付出多于所得 |
| 体克用 | 吉而费力 | 我能制它 | 事可成，但须亲力亲为 |
| 用克体 | 凶 | 事来压我 | 阻力、受制，防对方势强 |
| 体用比和 | 吉 | 同气相应 | 顺遂，同类相助，事半功倍 |

断时**先看克、再看生**：用克体最忌，须看体旺不旺——体旺能扛，体衰则凶。体生用虽泄，若用正是所求之财、所求之物，也可解作「投入换所得」，但要如实点出代价。

## 三、旺衰：以时令定卦气

八卦配五行：乾兑金、震巽木、坎水、离火、坤艮土。时令旺衰按**五行旺相休囚死**（《梅花易数·衰旺论》所论，正谓体气宜盛不宜衰）：

- 当令者**旺**，令生者**相**，生令者**休**，克令者**囚**，令克者**死**。
- 例：秋月金旺——乾兑旺、坎水相（金生水）、坤艮土休（土生金）、离火囚（火克金）、震巽木死（金克木）。
- 用法：体旺则能任事、能承压；体衰则力薄，凶象加倍。用旺克体更凶；用衰虽克体，凶减半而事迟。

白话：**旺衰就是「这卦赶不赶时令」**，得时的力量大，失时的力量小。月建看 `gua_now` 或 `gua_cast` 返回的 `time.monthBranch`，按节气定，不要拿农历月顶替。

## 四、互卦与变卦：看过程与结果

- **本卦**：现状、起因、当下之势。
- **互卦**：取本卦二、三、四爻为下卦，三、四、五爻为上卦，主事情**中途**与**内情**（`gua_cast` 返回 `hu`）。
- **变卦**：动爻阴阳一翻即成，主**结果与后势**（返回 `bian`；无动爻则无变卦）。
- 读序：本→互→变，一路自问「现在什么局面→中间起什么变化→最后落在哪里」。
- 细看：互卦若又克体，过程有阻；变卦生体，末路有救；变卦仍克体，须提前设防。

例：观梅占得泽火革，初爻动，互见乾巽，变泽山咸（《梅花易数·观梅占》）——本卦「革」言变，互卦乾巽见刚柔交涉，变卦「咸」主感应，故断次晚有邻女折花、堕伤其股之应。此例看的正是本、互、变三层。

## 五、三要与外应

《梅花易数·三要灵应篇》以**耳、目、心**为三要：耳听声、目见物、心触机。白话：起卦那一刻听到什么、看到什么、心里忽然动的那一念，都是卦的一部分。

《梅花易数·十应奥论》列十应——天时、地理、人事、时令、方卦、动物、静物、言语、声音、五色（篇末另附写字之应）。逐类查看：

| 类 | 看什么 | 喜应 | 忌应 |
|---|---|---|---|
| 天时 | 晴雨风云 | 晴朗、和风 | 骤雨、雷电 |
| 地理 | 所处高低明暗 | 明亮、开阔 | 阴暗、逼仄 |
| 人事 | 旁人言行 | 笑谈、相助 | 争吵、哭泣 |
| 时令 | 季节物候 | 当令之物 | 反季枯败 |
| 方卦 | 声音器物所来方位 | 合体用旺方 | 冲克之方 |
| 动物 | 所见禽兽虫鱼 | 吉禽瑞兽 | 鸦鸣犬吠、虫蚁乱 |
| 静物 | 所见器物 | 完好、齐整 | 破碎、倾倒 |
| 言语 | 入耳之语 | 吉语、善言 | 恶语、丧事之言 |
| 声音 | 音色清浊 | 清亮悠长 | 嘶哑急促 |
| 五色 | 当场所见主色 | 鲜明应吉 | 晦暗、污色 |

规矩：**外应只作辅证，不夺体用主断**；取当下第一念，不追第二念、不事后牵合。外应与体用同向则加力；相反则以体用为主，并注明「外应不合，事有反复」。

## 六、应期

梅花推应期常用四条线，取交集或取最有力者：

1. **卦数**：乾1兑2离3震4巽5坎6艮7坤8；以体用卦数、动爻数、上下卦数之和推。
2. **卦气**：旺相应速，休囚应迟；旺者以日计，衰者以旬月计。
3. **动爻**：动在第几爻，常应第几数之期（动在三，三日、三旬、三月）。
4. **事体**：近事以日时，常事以旬月，远事以年月；问「何时」才推，问「成否」不必硬给日期。

口诀：**旺相应速，休囚应迟；数取成卦，事分远近。** 给区间不给死数，如「约三到十日之内」，并注明所据。

## 七、从盘面到断语的检查清单

依次过一遍，缺一不可：

1. 起卦前调过 `gua_now` 否？四柱、月建、真太阳时对不对？
2. 「一问」是否明确？所问之事与体用是否对得上？
3. 体用是否取对？动爻落在哪一卦？
4. 生克方向是否核过（用生体≠体生用）？
5. 旺衰如何？体旺还是体衰？月建看没看？
6. 互卦讲过程，是否另有克体之象？
7. 变卦讲结果，是生体还是克体？
8. 外应是否同向？有无值得点出的当场之象？
9. 应期给区间，依据是哪一条？
10. 结论是否落到「可做的事」？有无越界（生死、医疗、投资、法律替代判断）？
11. 是否已用 `gua_case` 记录？应期是否写进 `followUpAt`？

## 八、常见错法

| 错法 | 说明 | 正办 |
|---|---|---|
| 体用取反 | 把动卦当体，吉凶全反 | 静者为体、动者为用，与 `tiYong` 复核 |
| 只按卦名断 | 「泰」未必吉、「剥」未必凶 | 卦名只是纲，体用生克才是肉 |
| 忽略月建旺衰 | 衰体受克也敢断吉 | 先看时令，再落断语 |
| 把互卦当结果 | 过程当结局，断早一步 | 本→互→变分三层 |
| 外应牵强堆砌 | 见什么都能圆，等于没断 | 只取第一念，一两条足够 |
| 应期报死日期 | 一旦不应，整卦失信 | 报区间与依据 |
| 用农历月当月建 | 节气未到，旺衰算错 | 月建看节气，用 `almanac.monthBranch` |
