# 八字（子平）断法

**先做**：调 `gua_now` 取「此刻此地」（当前时间用于定当前大运/流年，也核对时区地点）。再问清**出生三件套**：①公历出生年月日与时（几点几分；23:00 后属晚子时）；②性别（决定大运顺逆）；③出生地（真太阳时；不确定就用配置默认地点并说明）。三件套缺一不可，缺则先问，不猜。

然后用 `gua_bazi` 排盘：返回 `meta`（四柱/日主/属相/顺逆/起运）、`pillars`（四柱：十神、藏干、星运、自坐、空亡、纳音、常用神煞）、`dayun`（10 步，每步带 10 年流年与 12 个月流月）、`hints`。查古籍用 `gua_kb`（book 填「渊海子平」「三命通会」「滴天髓」「八字基础知识」「神煞大全」）；断毕用 `gua_case` 记档（问事、盘面摘要、断语、应期、标签）。

「先观月令，后看日主；旺衰既定，格局可分。」白话：月令是提纲，定日主旺衰先看月支；旺衰定了，才谈格局用神。

## 一、断盘硬顺序（逐条过，不跳步）

1. **定日主**：日柱天干（如丙火），先看它生在什么月令。
2. **看旺衰**：月令得气否、得地否（通根）、得生否（印比帮身）；再看三合六合、刑冲。
3. **定格局**：以月令藏干透干为主（正官/七杀/正财/偏财/食神/伤官/正印/偏印），特殊格局（建禄、阳刃、从格、化格）另论。
4. **取用神**：扶抑（弱则印比，强则财官食伤）、调候（寒暖燥湿，见《穷通宝鉴》路数）、通关、从势；用神要能落到具体十神与宫位。
5. **看大运**：每步大运的十神与命局关系；顺逆与起运岁数由引擎给出，不自己排。
6. **看流年**：流年干支与原局、大运的合冲刑害；重点看用神被引动还是被克。
7. **落应期**：给时间段与「什么现象算应验」，不把话说死。
8. **记档**：`gua_case` 记录；用户回来复盘时再 update，不主动追问。

## 二、十神速查（以日干为我）

| 十神 | 关系 | 取象 |
|---|---|---|
| 比肩 | 同我同阴阳 | 兄弟、同辈、自我、独立 |
| 劫财 | 同我异阴阳 | 竞争、朋友、破财、合作 |
| 食神 | 我生同阴阳 | 才艺、口福、子女（女命）、温和 |
| 伤官 | 我生异阴阳 | 表达、创新、锋芒、克官 |
| 偏财 | 我克同阴阳 | 意外财、父亲、经营、投机 |
| 正财 | 我克异阴阳 | 正财、妻子（男命）、务实 |
| 七杀 | 克我同阴阳 | 压力、权力、竞争、小人 |
| 正官 | 克我异阴阳 | 名位、规矩、丈夫（女命） |
| 偏印 | 生我同阴阳 | 偏才、灵感、孤独、后母 |
| 正印 | 生我异阴阳 | 母亲、学业、庇荫、文贵 |

## 三、旺衰与格局要点

- **得令**：月支为日主旺相之地（如丙火生巳午月）。
- **得地**：地支通根（藏干有日主同类），尤重日支、月支。
- **得生**：天干印比相助，地支生扶。
- **格局**：月令藏干透出天干者为格；不透者看月令本气。格局清纯（不被冲克）为贵，破格要说明。
- **用神**：弱命先扶身（印比），强命先泄耗（食伤财官）；寒暖燥湿失衡时先调候；两强相战取通关。
- **从格/化格**：日主极弱无根、满盘财官食伤，从势；合化须月令与化神得气，不可轻断。

## 四、大运与流年

- 大运由引擎排定（顺逆/起运/交运）；**不要手排**。一步大运十年，天干管前五年、地支管后五年是常用说法，断时可参考，不必机械。
- 流年看与原局、大运的**合冲刑害**：冲则动，合则绊，刑害多纠葛；流年引动用神则发，冲克用神则阻。
- 应期以「用神到位、忌神受制、宫位被引动」为准，给范围（某年到某年、某季），给验证现象。

## 五、合婚（要点）

合婚不是单看生肖：先看双方日主五行互补、夫妻宫（日支）合冲、用神是否互益；再看双方大运流年是否同步。合婚结论只谈相处与选择，不判「克夫克妻」。

## 六、输出规范（与 guashi-output 一致）

- 先盘后断：先说四柱、日主、旺衰、格局，再说结论与可做之事。
- 现代汉语；术语随手白话解释。
- 不宿命、不吓人、不决生死：不判寿元、不断疾病诊断、不判婚姻对错；健康提醒就医，法律提醒咨询律师，投资只谈风险偏好。
- 篇幅按 `guashi-output`：一般 300–800 字起，可写足；不注水。

## 七、常见错法

1. 只看日主不看月令，旺衰全凭感觉。
2. 见财官就断富贵，见七杀就断凶。
3. 把格局名硬套；一个盘可以无格，也可以格局不清。
4. 手排大运、把顺逆排反。
5. 流年当大运，或只看流年不看大运。
6. 拿旧书吓人断语直接转述（克妻、夭折、贫贱）。
7. 一个八字答所有问题：财看财星与财宫，官看官星与官宫，婚看夫妻宫与配偶星。
8. 手改盘面、凭记忆安十神藏干——盘面一律以 `gua_bazi` 为准。

## 八、与前端/工具衔接

- `gua_bazi` 的输出与 `client/bazi-chart` 前端契约同构：`meta + pillars + dayun` 可直接驱动细盘与大运/流年/流月切换。
- 引擎未算项（旺衰、格局、用神、人元司令、流日流时、分柱）在断语中如实说明由盘面推，不虚构盘面数据。
- 命盘属个人隐私：卦案只记必要信息，不主动外传。
