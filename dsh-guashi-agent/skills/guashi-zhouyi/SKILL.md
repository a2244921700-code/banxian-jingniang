# 周易经传用法

## 一、读一卦的次序

卦名卦象 → 卦辞 → 彖传 → 大象 → 爻辞 → 小象 →（乾坤另看文言）→ 通论（系辞、说卦、序卦、杂卦）。

- **卦辞**：一卦总纲，断大体吉凶；`gua_cast` / `gua_hexagram` 返回的 `guaCi` 即是。
- **彖传**：释卦辞，点出一卦之「时」与卦德。
- **大象**：「君子以……」，把卦象转成行事准则，最适合直接变成给用户的建议。
- **爻辞／小象**：落到具体一爻的处境；小象解释这一爻为何如此。
- **文言**：乾坤两卦专论，讲德性与时位。

## 二、卦德与卦时

**卦德**是八卦的本性，出自《周易·说卦》：

| 卦 | 德 | 白话 |
|---|---|---|
| 乾 | 健 | 刚健、主动、不息 |
| 坤 | 顺 | 柔顺、承载、包容 |
| 震 | 动 | 震动、奋起、惊惧 |
| 巽 | 入 | 渗入、顺从、渐进 |
| 坎 | 陷 | 陷落、险难、流动 |
| 离 | 丽 | 附着、光明、文明 |
| 艮 | 止 | 停止、界限、静守 |
| 兑 | 说（悦） | 喜悦、言语、交往 |

**卦时**是一卦所处的时势。断卦先问「此卦当何时」，再问「此位当如何」。《周易·泰·彖》以「天地交而万物通」释泰，《周易·否·彖》以「天地不交而万物不通」释否——泰否之别不在吉凶标签，而在交与不交。同一卦在不同时问，断语就不同。

白话：**卦德看「这卦什么性格」，卦时看「眼下什么季节」**；性格与季节相配则吉，相违则凶。实际占断中，卦时以 `gua_now` 所取的四柱月建为准（见 `guashi-casting`）。

## 三、爻位

六爻自下而上：初、二、三、四、五、上。

| 位 | 象 | 断法 |
|---|---|---|
| 初 | 事之始、位之下 | 潜藏待时，宜静不宜动 |
| 二 | 内卦之中、臣位 | 得中多誉，柔顺中正者吉 |
| 三 | 内卦之上、过中 | 多凶多惧，进退皆难，宜慎 |
| 四 | 近君之位 | 多惧，宜柔顺承上 |
| 五 | 外卦之中、君位 | 多功，得中得正者大吉 |
| 上 | 事之终、亢极 | 物极将反，宜退不宜进 |

- **当位**：阳爻居初、三、五（阳位），阴爻居二、四、上（阴位）为当位；反之为不当位，多主不顺。
- **得中**：二、五居上下卦之中，最贵；《周易》尚中，中常胜于正。
- **应**：初与四、二与五、三与上相应；一阴一阳为有应，主有援；同为阴或同为阳为无应，主孤立。
- **比**：相邻两爻为比，看亲比与否。
- 古训：《周易·系辞下》「二与四同功而异位，其善不同；二多誉，四多惧，近也」「三与五同功而异位，三多凶，五多功，贵贱之等也」。白话：爻位相同而处境不同，越靠近君位越要小心。

## 四、彖、象、文言怎么用

- **引彖定大势**：彖传一两句就把一卦的时与德说完，用来给整卦定性。
- **引大象给行动**：大象是「君子以……」的行事准则，可直接转成用户「该怎么做」。例：《周易·乾·象》「天行健，君子以自强不息」——天（乾）的运行刚健不止，君子效法它，自强不息。
- **引小象解爻**：小象点出爻辞吉凶的缘由。例：《周易·乾·象》（小象）「潜龙勿用，阳在下也」——阳爻处在最下位、力量未足，所以「勿用」是暂不施展，不是「没有用」。
- **文言只在乾坤用**：乾坤为六十四卦门户，文言讲元亨利贞四德。《周易·乾·文言》：「元者，善之长也；亨者，嘉之会也；利者，义之和也；贞者，事之干也」——元是众善之首，亨是美善的会聚，利是道义的和谐，贞是做事的主干。断卦讲德性层面时可引。

## 五、引经规范

1. **格式**：出处（书名·篇名）＋原文＋白话。例：《周易·乾·文言》「元者，善之长也」——元，是众善的首领。
2. **引一句，解一句**：不解释的引文等于没引；宁可少引，不可只引。
3. **短引**：一次不超过两句、约二十字，不整段抄。
4. **篇名要准**：卦辞、彖传、象传、小象、文言、系辞上、系辞下、说卦、序卦、杂卦，分清楚；拿不准就只写书名，不硬编篇名。
5. **不改原文**：异体字、通假字保留原貌，需要时括注今字；标点可加，字不可改。
6. **不冒充作者**：经传旧题孔子，引用只标篇名，不写「孔子说」。
7. **引完落断**：先引、再解、后断，三段分明，别让引文代替结论。
