# 大六壬断法

**先做**：调 `gua_now` 取实时时间、真太阳时、节气与地点——六壬定月将、定昼夜贵、定课体全赖时间；再 `gua_liuren`（daynight=`auto`）排盘：盘中已有月将、天地盘、四课、三传、天将、旬空与 `hints`。查典用 `gua_kb`（book 填「六壬」「六壬大全」「六壬指南」），断毕用 `gua_case` 记档。

「前后引从升迁吉，首尾相见始终宜；三传递生人荐举，三传互克众人欺。」（《六壬大全·毕法赋》）白话：课传层层递生则人相助，层层相克则众人相欺。

**不要自己心算三传**：九宗门取传以排盘引擎为准；若 `sanChuan.method` 是别责、八专等保守处理，照 `hints` 明说，只断大势。

## 一、操作顺序（硬顺序）

1. 问清一事，确认昼课或夜课（`daynight` 与 `hints` 的昼夜贵依据）。
2. 看月将加时：月将为事的时令，天地盘为生克与神煞的地基。
3. 看四课：日干为我，日支为彼、为事、为宅；四课上下生克定亲疏顺逆。
4. 看发用（初传）：先看课体名（`sanChuan.method`），再读三传始中终。
5. 看三传与日干、日支生克：生我者助，克我者阻，末传为结局。
6. 看天将与六亲落点：天将定事之情，生克定事之势。
7. 看神煞临何处：驿马、桃花、日德、旬空。
8. 定应期，落结论，`gua_case` 记档。

口诀：**月将加时定地盘，四课上下辨亲疏；三传始中终看事，天将神煞定情由。**

白话：四课＝日干、日支各带上下两神共四层；发用＝三传的第一传，即事情起头；天将＝十二位神煞，用来定事情的情状。

## 二、四课取用

| 课 | 位置 | 象 |
|---|---|---|
| 一课 | 日干上神 | 我之表面、当下作为 |
| 二课 | 干上神之上神 | 我之隐情、背后 |
| 三课 | 日支上神 | 对方、事体、宅之表面 |
| 四课 | 支上神之上神 | 对方隐情、事之源 |

- 四课上下**相生为顺、相克为逆**；日干上神克日干为「鬼临头」，主压力忧患；日支上神生日干为彼助我。
- 日干为我，**发用（初传）为事机**；中传为过程，末传为结局。三传生日干吉，克日干凶；三传空破则事虚。
- 事由己出者多从干起，事由外至者多从支起；干支上神俱生日干，得人和。

## 三、九宗门课体（对读 `sanChuan.method`）

| 课体 | 取法 | 判读要点 |
|---|---|---|
| 贼克 | 有下克上先取（贼），无则取上克下（克） | 事发于内、卑下犯上，主争、被动 |
| 比用 | 多课相克，取与日干阴阳相比者 | 同类相从，取亲者近者断 |
| 涉害 | 比用难定，较涉害深浅取深者 | 事多牵扯、层层受累，久而后定 |
| 遥克 | 无贼克而有遥克，取遥 | 事远而缓、须借外力 |
| 昴星 | 无克无遥 | 主静、守、机密不宣，宜静不宜动 |
| 别责 | 四课不全又能取合者 | 事有缺、须借力，古法细节各家小异 |
| 八专 | 日干寄宫与日支同位 | 主专一、私情、不清不明，宜谨守 |
| 伏吟 | 月将加时天地盘同位 | 事静不进、宜守旧，凶事亦不动而消 |
| 反吟 | 天地盘相冲 | 反复、动、去而复返，事多变 |

课体只定事之格局，吉凶仍看三传与日干生克。

## 五、昼夜贵人与神煞

- 天乙贵人：甲戊庚见丑（昼）未（夜），乙己见子申，丙丁见亥酉，壬癸见卯巳，辛见午寅。诀曰「甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎」（《六壬大全》）。
- 贵人临地盘亥至辰顺布，临巳至戌逆布；排盘已定，直接读 `tianJiang`。

| 神煞 | 取法（按日支） | 断 |
|---|---|---|
| 驿马 | 申子辰马寅，寅午戌马申，巳酉丑马亥，亥卯未马巳 | 行动、迁移、出行、调动 |
| 桃花 | 申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子 | 情色、喜庆、异性 |
| 日禄 | 甲寅、乙卯、丙戊巳、丁己午、庚申、辛酉、壬亥、癸子 | 自身根基、俸禄、得体 |
| 日德 | 甲己寅、乙庚申、丙辛巳、丁壬亥、戊癸巳（干合寄宫法，诸家小异） | 福善、化解、德助 |
| 旬空 | 按日柱（`xunKong`） | 事虚、人不在，待填实 |
| 月破 | 月建冲日支 | 事破，临用则凶，待合待值 |

神煞为辅助：不入四课三传者力弱；临发用、临日干者显；凶煞逢吉将可减。

## 六、应期

- 三传定始中终：初传为起事之期，末传为结局之期；应期多取初传、末传之支。
- 近事取日时，远事取月年；三传旺相速，休囚迟。
- 空待填实或冲空；破待合或待值；马星临用主速动；合待冲、冲待合。
- 六壬重「过程节点」：给「何时起、何时见结果」的时段，不硬报日子。

## 七、常见错法

1. 不辨昼夜贵人与顺逆（照盘读，勿自创）。
2. 自己心算三传，与盘面出入（以盘为准）。
3. 只看天将吉凶，不看四课三传生克。
4. 神煞喧宾夺主（神煞只是旁证）。
5. 伏吟反吟一律断凶（伏吟主静守，反吟主反复，吉凶看用神）。
6. 四课不全或别责、八专课硬套课体断语。
7. 拿六壬课套六爻六亲六神，或反之以六爻法断六壬。
8. 应期乱报；宜给过程与时段。
