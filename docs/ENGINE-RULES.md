## 1. 历法基础（所有术数共用）

文件：`lib/engine/almanac.js`

### 1.1 时间基准
- 所有输入先换算成**北京时间（UTC+8）民用时间**，与运行机器时区无关；内部用 UTC 视图承载 +08:00 墙上时间。
- 日界：**23:00**（子时换日）。23:00–23:59 为「晚子时」：
  - 默认：日柱取**次日**，时柱按次日日干起子时；
  - 八字/六爻/六壬/太乙走默认；
  - 奇门可用 `lateZi:'sameDay'` 改为「夜子时」：日柱不换，时柱按次日日干起子时。
- 真太阳时 = 北京时间 + (经度 − 120) × 4 分钟 + 均时差；只有传入经度且 `trueSolarTime !== false` 时启用。

### 1.2 四柱
- 年柱：以**立春**为界（不是正月初一）。
- 月柱：以十二「节」为界（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）。
- 日柱：儒略日整数公式，连续无跳变；1900–2100 与更早日期可用。
- 时柱：五鼠遁；日界按上述 23:00。
- 节气：Meeus 低精度太阳视黄经反解，误差约 0.01°（≈15 分钟），忽略 ΔT（2026 约 69 秒）；换算为北京时间。
- 农历：内置 1900–2100 年月份大小/闰月编码表，与香港天文台对照表核对；边界 1900-01-31 至 2100-12-31。
- 旬空：按日柱所在旬，取旬首前两位地支。

### 1.3 输出
`getAlmanac(date, {longitude?})` 返回：`ganzhi`（年/月/日/时）、`lunar`、`solarTerm`（当前/上一/下一）、`monthBranch`、`xunKong`、`effectiveDate`、`trueSolarTime` 等。各引擎在它的上面再做本术数排盘。

## 2. 八字（`lib/engine/bazi.js`）

### 2.1 输入与范围
- 输入：出生公历时间、性别（男/女）、可选出生地经度与是否用真太阳时。
- 输出：四柱、十神、藏干、十二长生（星运/自坐）、旬空、纳音、常用神煞子集、大运/流年/流月，及当前大运/流年索引。
- **不计算**：旺衰、格局、用神、人元司令、流日/流时、五柱分柱。

### 2.2 四柱与十神
- 四柱由 almanac 直接给出（立春换年、节气换月、23:00 换日）。
- 十神：以日干为我；同五行同阴阳=比肩，同五行异阴阳=劫财；我生同阴阳=食神、异=伤官；我克同=偏财、异=正财；克我同=七杀、异=正官；生我同=偏印、异=正印。
- 藏干表（子癸；丑己癸辛；寅甲丙戊；卯乙；辰戊乙癸；巳丙戊庚；午丁己；未己丁乙；申庚壬戊；酉辛；戌戊辛丁；亥壬甲）。
- 十二长生：按十干长生起点阳顺阴逆排「长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养」；同时给星运（日干对各柱地支）与自坐。
- 纳音：六十甲子纳音表；神煞为常用子集（桃花、驿马、华盖、将星、劫煞、亡神、孤辰、寡宿、天乙、文昌、禄神等）。

### 2.3 大运（`computeQiyun` + `buildDayun`）
- 顺逆：**阳年干男 / 阴年干女 → 顺行**；**阴年干男 / 阳年干女 → 逆行**。
- 起运：从出生时刻到最近一个「节」的日数：
  - 3 天 = 1 年；余数 1 天 = 4 个月；再余按 1 时 ≈ 10 日折算；
  - 代码实现：`years=floor(days/3)`，`months=floor(rem*4)`，`days=round(rem2*30)`，再进位。
- 交运：出生年 + 年数、月 + 月数、日 + 日数（公历近似；未做时辰级精算）。
- 大运：从月柱起，顺行/逆行各推一位，共 10 步、每步 10 年；每步含 10 个流年。
- 流年：以立春为界取年柱；流月：从该年「立春」起排 12 个节月（寅月起），月干按五虎遁。
- 当前大运/流年：以 `now` 的虚岁/公历年匹配。

### 2.4 已知偏差
- 起运/交运是公历近似，未按时辰精算；不同流派有「按日折年」「按刻折日」等差异。
- 神煞仅常用子集，未含全部门派；旺衰/格局/用神不在引擎。
- 晚子时按 23:00 换日；若师承「夜子时不换日」，结果会不同。

## 3. 紫微斗数（`lib/engine/ziwei.js` + `ziwei-data.js`）

### 3.1 输入与范围
- 输入：公历日期、性别、可选经度、闰月处理开关；输出十二宫、十四主星、辅星/煞星、四化、大限、当前流年。
- **不计算**：流年斗君、小限、自化飞星、三方四正连线。

### 3.2 关键口径
- 子时换日：23:00 起算次日（沿用 almanac 的 effectiveDay）。
- 闰月：默认 py-iztro 通行口径 `fixLeap=true`：闰月前半月算上月、后半月算下月。
- 四化：用**农历年干**（正月初一为界），不是立春。
- 晚子时：命宫/身宫/月系星按**当日**，紫微定位按**次日农历日**（与通行排盘一致）。
- 年干支：农历年干支（正月初一为界）。

### 3.3 排盘公式
- 命宫支：以寅宫起正月，顺数至生月，再逆数生时；代码：`mingZhiIndex = mod(2 + (month-1) - hourIndex)`（子=0、丑=1、寅=2）。
- 身宫支：`shenZhiIndex = mod(2 + (month-1) + hourIndex)`。
- 命宫天干：以年干起五虎遁（寅宫天干 = 年干五虎遁结果），顺排十二宫。
- 五行局：由命宫干支纳音五行转局（水二局、木三局、金四局、土五局、火六局）。
- 紫微：用《紫微斗数全书》紫微定位表，按**五行局 + 农历日**查表；表在 `ziwei-data.js`，经 py-iztro 对照。
- 天府：与紫微关于寅申轴对称；代码 `tianfuIdx = mod(2 - (ziweiIdx - 2))`。
- 十四主星：紫微系（紫微、天机、太阳、武曲、天同、廉贞）按固定偏移；天府系（天府、太阴、贪狼、巨门、天相、天梁、七杀、破军）按固定偏移。
- 辅星/煞星：左辅右弼（月）、文昌文曲（时）、天魁天钺（年干）、禄存（年干）、擎羊陀罗（禄存前后）、火星铃星（年支+时）、地空地劫（时）、天马（年支）。
- 四化：按农历年干查 `SIHUA_TABLE`，禄/权/科/忌。
- 大限：起于命宫，按五行局数起岁，阳男阴女顺行、阴男阳女逆行；每宫 10 年；当前虚岁按农历年计。
- 流年：取当前农历年支宫标「流年命宫」；仅作标记，未排斗君。

## 4. 奇门遁甲（`lib/engine/qimen.js`）

### 4.1 默认口径（✅ 已校核）
**时家 + 转盘 + 拆补法**；中五统一寄坤二；天禽随天芮；八门/八神不入中宫；晚子时默认 23:00 换日；旬空按**时柱**，驿马按**时支**三合马；日旬空/日马入 hints 参考。

### 4.2 定局
1. **拆补（默认）**：
   - 日柱逆推最近的「甲/己」日为符头；
   - 符头日支：子午卯酉=上元、寅申巳亥=中元、辰戌丑未=下元；
   - 当前节气 + 三元查二十四节气三元局数表（「冬至惊蛰一七四……」歌诀），得阴阳遁与局数。
2. **置闰（可选古法）**：
   - 建立符头链，每 15 日一符头，按节气顺推；
   - 芒种/大雪若符头超神 ≥8 日（`zhirunDays=9` 时可设 9），则置闰、重用本气三元；
   - 古籍：《遁甲演义·超神接气置闰诀》《奇门遁甲统宗·置闰法》《奇门宝鉴御定》。
3. **地盘三奇六仪**：戊己庚辛壬癸丁丙乙；阳遁自局数宫起按九宫序顺布，阴遁逆布。
4. **值符 / 值使**：
   - 时柱干支 → 旬首（甲子/甲戌/…）；旬首六仪（戊/己/庚/辛/壬/癸）所在地盘宫 = 值符原宫；
   - 值符 = 该宫本位九星；值使 = 该宫本位八门；
   - 旬首落中五：值符取天禽、值使取死门（阳遁 +「阳艮阴坤」寄宫时取生门），按寄宫发用。
5. **天盘干 / 九星（转盘）**：
   - 值符落宫 = 时干地盘宫（时干为甲则隐于旬首六仪）；
   - 天盘干与九星整体随值符转：环序 坎→艮→震→巽→离→坤→兑→乾；
   - 中五地盘干不动；天禽寄坤二与天芮同宫。
6. **八门**：
   - 值使「加时」：从值使本位宫起，按**旬内序数**（甲子时=0、乙丑=1…癸酉=9）阳顺阴逆走九宫；
   - 落中五寄宫；再整体按八门环序转。
7. **八神**：
   - 值符神起于值符落宫，阳遁顺时针、阴遁逆时针布「值符/螣蛇/太阴/六合/白虎/玄武/九地/九天」。
8. **空亡 / 驿马**：
   - 时柱旬空两支配宫标 `kong`；时支三合马标 `ma`；日空/日马入 hints。
9. **寄宫 / 晚子时 / 置闰天数**：
   - `jiGong='坤二'`（默认）或 `'阳艮阴坤'`；
   - `lateZi='nextDay'`（默认）或 `'sameDay'`（夜子时）；
   - `zhirunDays=8`（默认）或 `9`。

### 4.3 扩展盘式（⚠️ 实验）
1. **飞盘**（`method='飞盘'`）：
   - 值符星/值使门与转盘同源（旬首六仪本位）；
   - 值符落宫 = 时干地盘宫（甲隐旬首仪）；飞盘不寄宫，落中宫即在中宫；
   - 九星按宫序**恒顺飞**九宫（含中宫，九星俱全）；
   - 九神按阳顺阴逆飞九宫（飞盘九神：阳遁=值符/螣蛇/太阴/六合/勾陈/太常/朱雀/九地/九天；阴遁以白虎/玄武替换勾陈/朱雀）；
   - 八门从值使本位起，按旬内序数顺飞（默认跳中五；`feiPanUseZhongMen=true` 用九门含中门）；
   - 天盘干：星携本位地盘干（`diPan[星本位宫]`）。
2. **括囊**（`method='括囊'`）：
   - 在飞盘基础上，九星/八门/九神按**阳顺阴逆**飞布；
   - 另出「括囊门」层：值使门之对宫门，反向飞布（`palaces[].kuoNangDoor`）；
   - 天盘干默认随星携干；`kuoNangTianPanGanZiFei=true` 时「自飞九宫」：值符携旬首六仪从值符落宫起，阳顺阴逆布三奇六仪。

### 4.4 暗干五法（后四法 ⚠️ 实验）
1. **八门地盘携带之干（默认）**：门落宫携带该门本位宫的地盘干。
2. **时干找值使飞布，遇地盘相同入中**：以时干（甲隐旬首仪）自值使落宫起飞布九宫；若值使宫地盘干=时干，则改从中宫起；阳顺阴逆，干序按三奇六仪循环。
3. **时干找值使飞布，遇宫内有时干则入中**：同上，但值使宫内天盘干或地盘干见时干即入中起布。
4. **时干加值使转天盘，遇伏吟入中**：伏吟（坎宫地盘干=天盘干且星门本位）时，时干入中起布；否则自值使宫沿八宫环顺布。
5. **暗天干地支飞布法**：自旬首宫起，干序「癸乙丙丁戊己庚辛壬」，阳顺阴逆飞九宫。
- 转盘专属两法（1、4）在飞盘/括囊下按从真口径回退为第 5 法，`meta.anGanEffective` 如实回显。

### 4.5 穿壬（默认附加，⚠️ 实验）
每宫附四层：
- 地盘地支：宫辖地支（坎子、坤未申、震卯、巽辰巳、乾戌亥、兑酉、艮丑寅、离午）；
- 月将：按**中气换将**（雨水亥、春分戌、谷雨酉、小满申、夏至未、大暑午、处暑巳、秋分辰、霜降卯、小雪寅、冬至丑、大寒子）；
- 天盘支：月将加时，`天盘[地盘支] = 月将 + (地盘支 − 时支)`；
- 神将：十二天将，昼（卯至申）/夜按日干取贵人（《六壬元女经》表），贵人临地盘亥子丑寅卯辰顺布、巳午未申酉戌逆布；刻家局用刻干取贵；
- 建星：建除十二神。本引擎按**从真口径以时支起「建」**，与传统「以月建/日支起建」有流派差异。

## 5. 六爻（`lib/engine/liuyao.js`）

- 起卦：三枚铜钱，正=3、反=2；三枚和 6=老阴（动）、7=少阳、8=少阴、9=老阳（动）；自下而上 6 爻。也支持显式上下卦。
- 装卦：京房纳甲、八宫世应、六亲（以卦宫五行为我）、六神（按日干）、旬空（按日柱）、月建/日辰。
- 变卦：老阴/老阳动，动爻阴阳互变；输出本卦、变卦、互卦、动爻。
- **不计算**：用神取法、旺衰生克、吉凶、应期（skills 负责）。

## 6. 梅花易数（`lib/engine/meihua.js`）

- 时间卦：年支数 + 农历月 + 农历日 = 上卦基数（÷8 余数）；再加时支数 = 下卦基数；总数 ÷6 = 动爻（余 0 作 6）。
- 数字卦：第一数÷8 上卦、第二数÷8 下卦；第三数÷6 动爻；无第三数时用两数之和加时支÷6。
- 物数/字数卦：上数、下数、动爻（缺动爻则加时支）。
- 显式起卦：给上下卦（1–8 或卦名）与可选动爻。
- 体用：动爻所在卦为用，另一卦为体；按五行生克判体用关系；另出互卦、变卦、卦辞/爻辞。
- **不计算**：旺衰、三要十应、外应、应期（skills 负责）。

## 7. 大六壬（`lib/engine/liuren.js`）

- 月将：中气过宫（雨水亥将登明……大寒子将神后）；「节」沿用上一中气之将。
- 天地盘：月将加时，`天盘[地盘支] = 月将 + (地盘支 − 时支)`。
- 四课：日干寄宫起干阳/干阴，日支起支阳/支阴；一课下位按日干本身论五行。
- 三传：九宗门「贼克→比用→涉害→遥克」，别责/八专/昴星/伏吟/反吟依古法；涉害按《六壬大全》卷三浅深法；中传取初传之上神，末传取中传之上神。
- 十二天将：昼夜贵按日干（卯至申昼；《六壬元女经》表），贵人临地盘亥至辰顺布、巳至戌逆布。
- 旬空按日柱。
- 已知分歧：涉害起点/反吟驿马取支等，测试注释已注明与个别工具差异。

## 8. 太乙神数（`lib/engine/taiyi.js`）

- 积年：唐开元十二年甲子（724）积 1,937,281 算；积年 = 公元年 + 1,936,557。
- 年计太乙：积年 mod 360 → mod 72 → mod 24 → ÷3 得宫，命起一宫顺行八宫、不游中五。
- 天目/计神/合神/始击/主客算/主客大将参将/四神太乙：按《太乙金鏡式經》卷 01/02/07 及例盘实现。
- 月计/日计/时计：部分经典常数有夺文，引擎用天文二至与平均回归年推步，属近似；`meta.pending` 会列出待考项。
- **不计算**：掩迫囚击关格、主客胜负、三基五福、大游小游等断法。

## 10. 已知边界（统一口径）

- 引擎统一「只出盘，不出断」；断法由 skills + 知识库负责。
- 各术数流派差异不是 bug，但必须在断语/文档中说明；不能把本引擎口径说成唯一正确。
- 奇门实验模式默认全部带 `meta.experimental=true` 和 hints 首条「【实验·未校核】」；前端也显示「实验/待校核」。
- 八字/紫微经验校核主要针对 1900–2100；更早/更晚日期需自行核对节气/农历表。
- 太乙月/日/时计、奇门山向/罗盘/套玄空仍是占位/近似，不可用于实际断事。
- 不做：套八字、案例库、AI 提示词（作者明确要求）。
