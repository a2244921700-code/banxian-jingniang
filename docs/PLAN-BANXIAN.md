> 状态：**知识库搜集完成（2026-11-06）**。截图书目已基本收齐（八字 26/26、紫微 7 全文 + 1 提要、

> 目标：从「卦师」升级为「半仙」——在原有易占六门（梅花/六爻/奇门/六壬/太乙/周易）之外，
> 补上**命理三科**：八字（子平）、紫微斗数、七政四余（星学），并能断运程、看流年、批命局。

## 一、定位与人设

- 名号：**半仙·鲸娘**（仍住这台机器；鲸娘修行更进一步，由妖入半仙，掌「三命」）。
- 声口不变：是妖不是客服；断卦时认真，批命时更沉一点。
- 本事扩为「六占 + 三命」：占（梅花/六爻/奇门/六壬/太乙/周易）；命（八字/紫微/七政）。
- 命理输出规矩：
  1. 先定盘（四柱/星盘）再论断，盘面一律来自工具，不心算；
  2. 先看格局用神（八字）或命身三方四正（紫微），神煞只作辅参；
  3. 大运/流年/大限定应期，不空断吉凶；
  4. 不宿命、不吓人、不决生死；不判寿元、不诊断疾病、不替人做重大决定；
  5. 命理用于认识自己与择时，不是「改命」；现代生活取象落到可做的事。

## 三、引擎（engine/）

新增三块纯 ESM 模块（零依赖，沿用 almanac.js）：

1. `bazi.js`
   - 输入：出生公历日期时间 + 地点（经纬度，真太阳时换算）。
   - 功能：四柱（年/月/日/时，沿用子时换日与节气月建）、藏干、十神、纳音、空亡、
     旺衰（得令得地得势粗判 + 月令权重）、格局（正格/建禄/阳刃/外格判定 + 用神候选扶抑/调候）、
     大运（顺逆、起运岁数「三日为年」）、流年、常用神煞（与 神煞大全 表对齐，作为客观计算）。
   - 输出：盘面 JSON + hints；**不下吉凶断语**（断法归 skills）。
2. `ziwei.js`
   - 输入：农历生日（时辰）+ 性别；农历换算用现有 almanac。
   - 功能：五行局、安紫微/天府系、十四主星、辅星（昌曲魁钺禄存擎羊陀罗火铃空劫四化）、
     十二宫（命身/兄弟/夫妻/子女/财帛/疾厄/迁移/交友/官禄/田宅/福德/父母）、
     四化、大限/流年宫位、三方四正。
3. `qizheng.js`（二期，可选）
   - 七政四余需星历：先用简化「黄道十二宫 + 七政位置表查表」；若精度不足，二期只出知识+人工判断，
     排盘先不自动化，避免假精确。
